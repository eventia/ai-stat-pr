### 페이지 07. 본문 구성 원칙 복습, 분야별·항목별 단락

표준 보도자료 본문 구성 원칙 (1차시 복습)

- 하나의 단락은 하나의 소주제만 다룸 (예: 품목별 동향, 지역별 동향을 별도 단락으로 분리)

### 페이지 10. 소재를 단락으로 확장하는 프롬프트 설계

단락 확장 프롬프트 예시

```
아래 그래프 설명 소재를 바탕으로, 통계 보도자료의 본문 한 단락(3~4문장)을 작성해 주세요.
조건: 두괄식 구조(핵심 수치 먼저), 제공된 사실 외 새로운 내용 추가 금지

소주제: 품목별 동향
설명 소재: 의류 65,000억 원(1위), 가전 52,000억 원(2위), 기타 10,000억 원(최하위)
```

> **[Note]** 6차시에서 만든 짧은 그래프 설명문 한 줄을 그대로 본문에 쓰기에는 정보량이 부족합니다. 그래서 이 소재를 프롬프트에 넣어서, 소주제와 관련 소재를 함께 전달하며 두괄식 구조를 갖춘 완결된 문단으로 확장하도록 요청합니다. 화면의 예시처럼 "제공된 사실 외 새로운 내용 추가 금지"라는 조건을 넣는 것을 잊지 마세요. 이 조건이 있어야 AI가 새로운 사실을 지어내지 않고 주어진 소재 안에서만 문장을 풍부하게 만들어줍니다.

### 페이지 11. Python 코드, 단락 확장 API 호출

단락 생성 함수

```python
def expand_to_paragraph(subtopic: str, source_facts: str) -> str:
    prompt = f"""아래 그래프 설명 소재를 바탕으로 통계 보도자료의 본문 한 단락(3~4문장)을
작성해 주세요. 두괄식 구조를 따르고, 제공된 사실 외의 내용은 추가하지 마세요.

소주제: {subtopic}
설명 소재: {source_facts}"""

    message = client.messages.create(
        model=MODEL_NAME, max_tokens=400,  # MODEL_NAME은 4차시에서 정의한 상수를 재사용
        messages=[{"role": "user", "content": prompt}]
    )
    return message.content[0].text

paragraph = expand_to_paragraph("품목별 동향", "의류 65,000억 원(1위), 가전 52,000억 원(2위)")
```

> **[Note]** 방금 배운 프롬프트를 함수로 만든 것이 expand_to_paragraph입니다. 소주제와 설명 소재 두 가지만 입력하면 하나의 완결된 본문 단락을 자동으로 생성해 줍니다. 이 함수는 특정 지표명에 얽매이지 않고 소주제와 소재라는 일반적인 두 인자만 받기 때문에, 나중에 다른 통계표를 다루는 경우에도 수정 없이 그대로 재사용할 수 있는 범용 함수입니다. 이 함수를 여러 소주제에 반복 적용하면 본문 전체를 구성하는 단락들을 빠르게 만들 수 있습니다.

### 페이지 12. 단락 간 흐름과 연결어 처리

자연스러운 연결을 위한 연결어 프롬프트 조건

```
직전 단락 요약: "품목별로는 의류의 거래액이 가장 컸다."
다음 단락은 이 내용에 이어지는 자연스러운 연결어(예: "한편,", "이와 함께,")로 시작해 주세요.
```

> **[Note]** 단락을 각각 따로 생성하면 글 전체가 뚝뚝 끊어지는 느낌을 줄 수 있습니다. 이걸 방지하려면 직전 단락의 요약을 다음 단락 생성 프롬프트에 함께 전달해서, "한편,", "이와 함께," 같은 연결어로 자연스럽게 이어지도록 지시하면 됩니다. 다만 실제 구현에서는 이렇게 매번 직전 단락 요약을 프롬프트에 넣는 대신, 더 간단한 방법으로 연결어를 처리합니다. 바로 다음 페이지에서 그 방법을 코드로 보여드리겠습니다.

### 페이지 13. Python 코드, 여러 단락을 순서대로 생성하는 루프

본문 전체 생성 루프

```python
subtopics = [
    ("품목별 동향", "의류 65,000억 원(1위), 가전 52,000억 원(2위), 기타 10,000억 원(최하위)"),
    ("품목별 비중", "의류 32.4%, 가전 25.9%, 식품 23.9%"),
    ("시계열 동향", "최근 4개월 연속 증가세, 2026년 1월 역대 최대치")
]

paragraphs = []
연결어_목록 = ["", "한편, ", "아울러, "]
for i, (subtopic, facts) in enumerate(subtopics):
    본문단락 = expand_to_paragraph(subtopic, facts)
    if i > 0:
        본문단락 = 연결어_목록[min(i, len(연결어_목록) - 1)] + 본문단락[0].lower() + 본문단락[1:]
    paragraphs.append(본문단락)
```

> **[Note]** 정리해둔 소주제-소재 목록을 순서대로 반복하면서 단락을 하나씩 생성하는 코드입니다. 앞서 언급한 "직전 단락 요약을 다음 프롬프트에 전달"하는 방식 대신, 여기서는 훨씬 간단한 방법을 씁니다. 연결어_목록이라는 배열에 "", "한편, ", "아울러, "를 순서대로 준비해두고, 두 번째 단락부터는 이 연결어를 문장 맨 앞에 그대로 붙여주는 방식입니다. 이렇게 하면 AI에게 매번 복잡한 맥락을 전달할 필요 없이도 충분히 자연스러운 흐름을 만들 수 있습니다. 참고로 연결어를 붙일 때 본문단락의 첫 글자를 소문자로, 정확히는 국문에서는 조사 앞부분을 소문자 처리하듯 다듬어서 "한편, 의류가"처럼 자연스럽게 이어지도록 처리한다는 점도 코드에서 확인해 주세요.

### 페이지 14. Python 코드, generate_body_paragraphs 함수로 통합

```python
def generate_body_paragraphs(data: dict) -> list:
    """시각자료설명 목록을 소주제별 본문 단락으로 확장하고, 표준 '본문' 스키마로 반환한다."""
    연결어_목록 = ["", "한편, ", "아울러, "]
    본문 = []
    for i, 항목 in enumerate(data.get("시각자료설명", [])):
        subtopic = 항목["소주제"]
        내용 = expand_to_paragraph(subtopic, 항목["설명문"])
        if i > 0:
            내용 = 연결어_목록[min(i, len(연결어_목록) - 1)] + 내용[0].lower() + 내용[1:]
        본문.append({"소주제": subtopic, "내용": 내용})
    return 본문

data["본문"] = generate_body_paragraphs(data)
```

> **[Note]** 방금 만든 반복문 로직을 표준 데이터 스키마에 맞게 감싼 것이 generate_body_paragraphs 함수입니다. 이 함수는 손으로 소주제 목록을 적어주는 대신, 6차시에서 만든 "시각자료설명" 목록을 그대로 입력받습니다. 시각자료설명의 각 항목에서 소주제와 설명문을 꺼내 expand_to_paragraph에 넘기고, 연결어까지 붙여서 "소주제"와 "내용"이라는 두 필드를 가진 딕셔너리 리스트, 즉 표준 "본문" 스키마로 반환합니다. 이렇게 만들어두면 10차시의 전체 파이프라인은 이 함수 하나만 호출해도 시각자료설명 개수만큼 본문 단락이 자동으로 만들어집니다.

### 페이지 18. 결과 검증, 수치 대조와 중복 표현 점검

본문 검증 체크리스트

1. 각 단락의 수치가 원본 계산지표 및 5차시 통계해석결과와 일치하는가
2. 동일한 표현이나 문장 구조가 여러 단락에서 반복되지 않는가
3. 리드문에서 이미 언급한 내용이 본문에서 불필요하게 중복되지 않는가

```python
for p in paragraphs:
    print(verify_numbers(p, data))
```

> **[Note]** 리드문과 마찬가지로 본문의 모든 단락에 대해서도 수치 검증을 반복 실행해야 합니다. 코드에서 보시는 것처럼 각 단락에 대해 4차시에서 만든 verify_numbers 함수를 하나씩 돌려서 확인합니다. 그와 더불어, 각 단락의 수치가 원본 계산지표나 통계해석결과와 일치하는지, 여러 단락이 비슷한 표현이나 문장 구조로 반복되지는 않는지, 리드문에서 이미 언급한 내용이 본문에서 불필요하게 중복되지는 않는지까지 사람이 직접 훑어보며 검토하는 습관이 필요합니다.

### 페이지 21. 8차시 정리와 9차시 예고

8차시 핵심 요약

- 그래프 설명 소재를 소주제 단위로 정리한 뒤, 두괄식 구조의 본문 단락으로 확장함
- 연결어와 이전 단락 요약을 프롬프트에 반영하여 자연스러운 흐름을 유지함

> **[Note]** 오늘은 그래프 설명 소재를 소주제 단위로 정리한 뒤, 두괄식 구조의 본문 단락으로 확장하는 방법을 배웠고, 연결어를 이용해서 여러 단락이 자연스러운 흐름을 갖도록 만들었으며, 이 단락들을 하나로 조립하고 수치 검증까지 반복 적용하는 과정을 완성했습니다. 이번 시간으로 리드문에 이어지는 보도자료 본문 전체가 완성되었습니다. 다음 9차시에서는 지금까지 작성한 초안 전체의 문체를 통일하고, 수치·단위 오류를 자동으로 검수하며, AI 감수 모델을 통해 최종 품질을 검증하는 방법을 배우겠습니다.
