### 페이지 09. Python 코드, load_input 함수로 xlsx/PDF 입력 통합

```python
import os
import pandas as pd
import pdfplumber
from modules.config import REQUIRED_FIELDS
from modules.stats import derive_history_indicators

def load_input(파일경로: str) -> dict:
    """확장자에 따라 xlsx 또는 PDF 원자료를 읽어 raw dict로 반환한다."""
    확장자 = os.path.splitext(파일경로)[1].lower()

    if 확장자 == ".xlsx":
        엑셀 = pd.ExcelFile(파일경로)
        df = pd.read_excel(엑셀, sheet_name=엑셀.sheet_names[0])
        row = df.iloc[0].to_dict()
        raw = {
            "제목": f"{row.get('연월', '')} 온라인쇼핑 동향",
            "계산지표": {field: row[field] for field in REQUIRED_FIELDS},
            "원문": row.get("원문", ""),
        }
        if "품목별지표" in df.columns:
            raw["품목별지표"] = row["품목별지표"]  # 실제 코드는 JSON 문자열이면 파싱까지 처리

        if "이력" in 엑셀.sheet_names:
            이력_df = pd.read_excel(엑셀, sheet_name="이력")
            history = [{"연월": str(r["연월"]), "값": r[REQUIRED_FIELDS[0]]} for _, r in 이력_df.iterrows()]
            raw["월별이력"] = history + [{"연월": str(row.get("연월", "")), "값": row[REQUIRED_FIELDS[0]]}]
            계산됨 = derive_history_indicators(history, str(row.get("연월", "")), row[REQUIRED_FIELDS[0]])
            raw.setdefault("역대최대여부", 계산됨["역대최대여부"])
            raw.setdefault("최근3개월증감률", 계산됨["최근3개월증감률"])
        return raw
    elif 확장자 == ".pdf":
        with pdfplumber.open(파일경로) as pdf:
            full_text = "\n".join(page.extract_text() or "" for page in pdf.pages)
        return {"원문": full_text}
    else:
        raise ValueError(f"지원하지 않는 파일 형식입니다: {확장자}")
```

> **[Note]** 방금 배운 xlsx 읽기와 PDF 읽기를 확장자에 따라 알아서 분기하는 하나의 함수로 통합한 것이 load_input입니다. 확장자가 xlsx이면 첫 번째 시트를 읽어서 필수 계산지표 필드를 표준 형태로 매핑하고, PDF이면 페이지별 텍스트를 이어 붙여 원문 필드에 담습니다. 여기서 눈여겨보실 부분이 "이력" 시트를 처리하는 부분입니다. 만약 xlsx 파일에 "이력"이라는 이름의 시트가 있고 거기에 연월과 총거래액 두 컬럼만 있다면, 이전 차시에서 배운 derive_history_indicators 함수를 자동으로 호출해서 역대최대여부와 최근3개월증감률을 계산해 줍니다. 즉 담당자가 "이번 달이 역대 최대인지"를 직접 조사해서 입력할 필요 없이, 과거 실적 시트만 준비해두면 프로그램이 알아서 판단합니다. 다만 만약 담당자가 역대최대여부나 최근3개월증감률 열을 xlsx에 이미 직접 입력해두었다면, 그 값을 자동 계산 결과보다 우선해서 사용하도록 setdefault를 사용했습니다. 한 가지 더 기억할 점은, 이 load_input 함수는 계산지표, 즉 총거래액이나 증감률 같은 값이 xlsx에 이미 채워져 있다고 가정한다는 것입니다. 만약 원자료가 아직 집계도 되지 않은 개별 기록이라면, 계산을 전혀 하지 않고 그대로 읽기만 하는 또 다른 형태의 입력 함수가 필요한데, 이런 경우는 이전 차시에서 배운 표본 사업체 매출 데이터처럼 별도의 계산 단계와 조합해서 처리합니다.

### 페이지 10. 핵심지표 선정 기준 복습, 필수·선택·참고

핵심지표 선정 3단계 기준 (이전 차시 복습)

- 필수 항목: 제목과 리드문에 반드시 포함 (예: 총거래액, 전월대비·전년동월대비증감률)
- 선택 항목: 본문 부연 설명에 활용 (예: 품목별 비중, 순위)
- 참고 항목: 문맥 이해용 배경 정보 (예: 공표일자, 자료출처)

> **[Note]** 리드문에 모든 숫자를 다 담을 수는 없으므로, 이전 차시에서 배운 필수·선택·참고 항목 구분 기준을 다시 떠올려 보겠습니다. 필수 항목은 총거래액이나 증감률처럼 제목과 리드문에 반드시 들어가야 하는 지표이고, 선택 항목은 품목별 비중이나 순위처럼 본문에서 부연 설명할 때 쓰는 지표이며, 참고 항목은 공표일자나 자료출처처럼 문맥 이해를 돕는 배경 정보입니다. 오늘은 이 중에서 필수 항목만 자동으로 골라내는 코드를 만들어 보겠습니다.

### 페이지 11. Python 코드, 핵심지표 자동 선정 로직

필수 항목만 추출하는 함수

```python
REQUIRED_FIELDS = ["총거래액", "전월대비증감률", "전년동월대비증감률"]

def select_core_indicators(계산지표: dict) -> dict:
    return {k: v for k, v in 계산지표.items() if k in REQUIRED_FIELDS}

core = select_core_indicators(data["계산지표"])
print(core)
```

> **[Note]** REQUIRED_FIELDS라는 목록에 미리 등록해둔 필수 항목명을 기준으로, 전체 계산지표 중에서 리드문 작성에 꼭 필요한 지표만 자동으로 걸러내는 함수가 select_core_indicators입니다. 딕셔너리 컴프리헨션 한 줄로, 계산지표 안의 항목 중 REQUIRED_FIELDS에 있는 이름과 일치하는 것만 남기는 방식입니다. 이렇게 선별된 핵심지표가 다음 소주제에서 만들 프롬프트의 재료가 됩니다.

### 페이지 15. 리드문(6하원칙) 생성 프롬프트 설계

보도자료의 첫 문단(리드문)을 3~4문장으로 작성해 주세요.

### 페이지 16. Python 코드, 제목·부제·리드문 생성 API 호출

통합 생성 함수

```python
def build_headline_prompt(core: dict, special_points: list) -> str:
    """핵심지표와 특이점 목록을 바탕으로 제목·부제·리드문 생성 프롬프트를 만든다."""
    지표문장 = ", ".join(f"{k} {v}" for k, v in core.items())
    특이점문장 = ", ".join(special_points)
    return f"""아래 정보를 바탕으로 다음 3가지를 JSON으로 작성해 주세요.
1) 제목(15자 내외, 핵심 수치 또는 증감 방향 포함)
2) 부제(제목과 중복되지 않는 두 번째 정보, 25자 내외)
3) 리드문(6하원칙에 따라 3~4문장)

핵심지표: {지표문장}
특이사항: {특이점문장}

결과는 반드시 아래 JSON 형식으로만 출력하십시오.
{{"제목": "...", "부제": "...", "리드문": "..."}}"""

def generate_headline_set(data: dict) -> dict:
    core = select_core_indicators(data["계산지표"])
    prompt = build_headline_prompt(core, data["통계해석결과"]["특이점목록"])

    message = client.messages.create(
        model=MODEL_NAME, max_tokens=600,
        system="통계청 보도자료 작성 담당자로서 제공된 사실만 사용하여 "
               "JSON 형식으로 답하십시오.",
        messages=[{"role": "user", "content": prompt}]
    )
    return parse_json_response(message.content[0].text)

headline_set = generate_headline_set(data)
```

> **[Note]** 지금까지 따로 배운 제목, 부제, 리드문 프롬프트를 build_headline_prompt라는 하나의 함수로 합쳤습니다. 이 함수는 핵심지표와 특이점 목록을 받아서, 세 가지를 한 번에 JSON 형식으로 요청하는 프롬프트 문자열을 만듭니다. 그리고 generate_headline_set 함수는 select_core_indicators로 핵심지표를 고르고, build_headline_prompt로 프롬프트를 만들고, client.messages.create로 API를 호출한 뒤, 이전 차시에서 만든 parse_json_response로 결과를 파싱하는 전 과정을 하나로 묶습니다. 여기서 model 인자에는 이전 차시에서 정의한 MODEL_NAME 상수를 그대로 재사용하고 있다는 점도 확인해 주세요. 표준 데이터 하나만 입력하면 제목, 부제, 리드문이 한 번에 생성되는 구조입니다.

### 페이지 19. 여러 후보 중 선택 기준

후보 선택 시 고려할 기준

- 핵심 수치가 정확하게 표현되었는가
- 문장 길이가 제목 15자, 부제 25자 내외의 조건을 지켰는가
- 가장 특이한 사실(역대 최대 등)이 제목 또는 부제에 드러나는가
- 여러 후보 중 가장 간결하면서도 정보 손실이 없는 문장을 최종 채택

> **[Note]** AI는 보통 여러 개의 후보를 생성하므로, 정해진 기준에 따라 가장 적합한 후보를 사람이 최종적으로 선택하는 절차가 필요합니다. 확인할 기준은 네 가지입니다. 핵심 수치가 정확하게 표현되었는지, 글자 수 조건을 지켰는지, 가장 특이한 사실이 제목이나 부제에 잘 드러나는지, 그리고 여러 후보 중 가장 간결하면서도 정보 손실이 없는지입니다. 이 선택 과정 자체는 프로그램으로 우선순위를 매길 수도 있지만, 최종 채택만큼은 담당자가 직접 확인하는 것이 원칙입니다.

### 페이지 22. 정리하기

1. xlsx와 PDF, 두 가지 원자료 입력 처리
  - pandas의 read_excel과 pdfplumber로 엑셀과 PDF 원자료를 각각 읽어오고, load_input 함수로 확장자에 따라 자동으로 분기해서 표준 형태로 통합하는 방법을 배웠습니다.
