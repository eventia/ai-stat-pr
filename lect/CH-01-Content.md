# 페이지 03. 도입

통계 자료를 바탕으로 보도자료나 리포트를 작성해 보신 적이 있으신가요? 복잡한 표에서 필요한 수치를 일일이 확인하고, 전월이나 전년 대비 증감률을 계산한 뒤, 이를 자연스러운 문장으로 옮겨 적는 과정은 생각보다 많은 시간과 정성이 들어갑니다. 숫자 하나, 단위 하나라도 틀릴까 봐 몇 번이고 눈으로 검수해야 하죠.
최근에는 이러한 반복적인 수치 가공과 문장 작성 업무를 AI가 보조해 주는 기술이 주목받고 있습니다. 사람이 일일이 문장을 쓰는 대신 AI가 수치의 패턴을 읽고 초안을 작성해 주면, 담당자는 검수와 판단이라는 더 중요한 일에 집중할 수 있게 되는 것입니다.
이 과정에서 '과연 AI가 쓴 숫자를 온전히 믿어도 될까?', '입력한 중요한 데이터가 외부에 유출되지는 않을까?' 하는 걱정이 앞서기 마련입니다. 우리는 종종 국가와 세계적인 컴퓨터 기업들이 치명적인 오류를 내거나 해킹사고를 당하는 일들을 뉴스를 통해 접하곤 합니다. 뉴스에 나오지 않는 일들까지 조사해본다면 엄청나게 많은 사건과 사고들이 있는 것이 현실입니다. 이런 현실속에서 'AI는 나보다 똑똑하니, AI가 해준 답은 틀림없이 맞을거야'라는 생각은 순진한 생각일 수 있습니다. 의심하고, 한번 더 검토해서 잘못된 결과가 나오지 않도록 하는 것과 잘못된 결과가 나오더라도 그것을 파악해 낼수 있는 이성적이고 합리적인 접근이 필요합니다. 
이번 과정은 프로그래밍이나 AI에 대한 전문 지식이 없더라도 누구나 쉽게 따라 할 수 있도록 구성되었습니다. AI를 활용해 수치 계산의 번거로움을 줄이고, 입력한 정보가 외부에 유출되거나 학습되지 않는 안전한 환경 속에서 통계 보도자료 초안을 손쉽게 만들어내는 방법, 그 유용한 첫걸음을 지금부터 함께 시작해 보겠습니다.

### 페이지 06. 현행 보도자료 작성 방식의 한계 및 문제점

수작업 보도자료 작성 시 발생하는 4가지 주요 어려움

- 수치 산출의 번거로움: 대용량 통계표 가공 시, 단위나 수식을 일일이 확인해야 하여 오류 위험 존재
- 문장 작성의 부담: 단순히 숫자만 나열하는 것을 넘어, 독자가 이해하기 쉬운 문맥을 구성하는데 많은 시간 소요
- 검수의 피로도: 퍼센트(%)와 퍼센트포인트(%p)의 구분, 단락 간 숫자 일치 여부를 눈으로 검수하는 부담
- 시간적 압박: 정해진 배포 시점까지 다각도의 깊이 있는 분석문을 작성하기에 시간이 부족함

> **[Note]** 기존의 수작업 보도자료 작성 방식을 살펴보면 크게 네 가지 어려움이 있습니다. 첫째, 복잡한 통계표를 일일이 가공할 때 단위나 수식 계산에서 실수가 생기기 쉽습니다. 둘째, 숫자를 의미 있는 문장으로 풀어내는 데 많은 시간이 걸립니다. 셋째, %와 %p 구분처럼 미세한 표기 오류를 눈으로 일일이 검수해야 하며, 넷째, 긴박한 배포 일정 때문에 심도 있는 분석을 진행하기 어렵습니다.

### 페이지 07. AI 기반 보도자료 자동화 5단계 파이프라인

5단계 파이프라인 구조

1. 수집: 통계 시스템 및 문서 내 필요 수치 데이터 자동 수집
2. 정제: AI 처리가 용이한 표준 데이터 형태로의 정제 및 정리
3. 분석: 증감률, 비중, 역대 최고, 최저치 등 주요 변화 지표 연산
4. 작성: AI 모델 활용 제목, 요약문 및 본문 초안 작성
5. 검수: 원본 데이터 대조를 통한 수치 자동 검증 및 문체 교정

> **[Note]** 이러한 문제를 해결하기 위해 제시하는 5단계 파이프라인입니다. 1단계 수집에서 통계 데이터를 읽어오고, 2단계 정제에서 깔끔한 형태로 표준화합니다. 3단계 분석에서 증감률과 특이점을 연산한 뒤, 4단계 작성에서 AI가 보도자료 초안을 만듭니다. 마지막 5단계 검수에서 수치가 정확한지 검증하고 문장을 다듬어 최종 완성본을 도출합니다.

---

### 페이지 08. 수치 정확성(정합성)을 확보하는 3단계 안전장치

3단계 안전장치 구조

1. 1단계 (정확한 연산 전담): 모든 숫자 계산(증감률, 비중 등)은 컴퓨터 프로그램 알고리즘이 직접 수행하며, AI에게 계산을 맡기지 않음
2. 2단계 (검증된 수치 제공): 이미 완벽하게 계산된 결과 숫자만을 AI에게 입력하여 문장을 작성하도록 유도
3. 3단계 (자동 교차 검증): AI가 만들어낸 문장 속의 숫자를 원본 데이터와 1대1로 비교하여 틀린 부분이 없는지 최종 확인

> **[Note]** 보도자료 작성 시 가장 중요한 것은 단 하나의 수치 오차도 허용하지 않는 정확성입니다. 핵심 원칙은 수치 계산을 AI 모델 자체에 맡기지 않는 것입니다. 계산은 정확한 컴퓨터 프로그램 알고리즘이 완벽히 수행하고, AI는 그 계산 결과만을 전달받아 문장을 가공하도록 역할을 명확히 분리하여 오류를 차단합니다.

### 페이지 09. 표준 통계 보도자료의 핵심 구성 요소

구성 요소 블록

- 제목 및 부제: 핵심 지표의 변화를 한눈에 보여주는 요약 문구
- 리드문(첫 문단): 6하 원칙에 따라 핵심 내용과 전년 대비 변화를 요약한 문장
- 세부 본문: 분야별, 항목별 동향을 논리적인 단락으로 나누어 설명
- 시각자료 설명문: 표나 그래프가 의미하는 추세와 특징을 설명하는 문구

> **[Note]** 일반적인 통계 보도자료는 제목과 부제, 첫 문단인 리드문, 세부 본문, 그리고 시각자료 설명문으로 구성됩니다. 제목은 핵심 지표를 보여주고, 리드문은 주요 결론을 요약합니다. AI 시스템이 이러한 표준 작성 규격에 맞추어 문장을 작성하도록 체계적으로 설계를 진행합니다.

### 페이지 10. 보도자료 배포 절차와 공표 전 보안 통제

배포 프로세스

1. 통계 자료 가공
2. 외부 유출이 차단된 환경에서 AI 초안 작성
3. 작성자 직접 검수 및 승인
4. 사전 배포 (엠바고)
5. 공식 공표

> **[Note]** 통계 보도자료는 정해진 공표 시점까지 철저한 보안이 유지되어야 하는 사전 보안 대상 문서입니다. AI 도구를 활용하더라도 최종 확인과 승인은 반드시 사람이 직접 수행해야 합니다. 또한 배포 전 미공개 데이터가 외부망으로 유출되지 않도록 안전하게 격리된 환경에서 작성이 진행되어야 합니다.

### 페이지 14. AI, 머신러닝, 딥러닝, 생성형 AI의 관계

포함 관계 동심원 구조

- 인공지능: 기계가 인간의 행동을 모방 (기존 프로그래밍 포함)
- 기계학습: 인공지능 중 코드로 명시하지 않은 동작을 데이터를 이용해 스스로 학습
- 딥러닝: 기계학습 중 DNN(Deep Neural Network)을 이용한 분야
- 생성형 AI, 대화형 모델(LLM): 문맥을 이해하고 새로운 글이나 이미지를 만들어 내는 기술

> **[Note]** 가장 넓은 개념인 인공지능 안에 데이터를 통해 학습하는 머신러닝이 있고, 그 안에 신경망을 모방한 딥러닝이 있습니다. 딥러닝이 발전하여 현재 생성형 AI의 기본이 되는 트랜스포머 모델을 만들어 냈습니다. 우리가 사용할 AI 모델은 문맥을 이해하고 글을 작성하는 생성형 AI 기술에 해당합니다.

### 페이지 15. 컴퓨터가 사람의 말을 이해하는 기술(자연어 처리)의 발전 과정

4단계 발전 과정

1. 단순 규칙 방식: 정해진 단어, 규칙만으로 텍스트 구분 (문맥 이해 불가)
2. 통계적 학습 방식: 단어의 출현 빈도를 계산하여 분석 (BOW 등)
3. 신경망 학습 방식: 단어와 단어 사이의 연관성 파악 (RNN, Transformer)
4. 최신 AI 모델 방식: 문장 전체의 고차원적 문맥과 의도를 완벽히 이해 (Agent System)

> **[Note]** 사람이 사용하는 언어를 컴퓨터가 이해하도록 만드는 기술을 자연어 처리라고 합니다. 과거에는 정해진 단어 검색 수준에 그쳤지만, 현재 최신 AI 기술은 문장 전체의 흐름과 맥락을 깊이 있게 이해하는 수준으로 발전하였습니다.

### 페이지 16. 방대한 글에서 핵심 정보만 뽑아내는 3가지 기술

3대 주요 텍스트마이닝 기술

- 형태소 분석: 문장을 가장 작은 의미 단위(명사, 동사 등)로 쪼개어 분석하는 기술
- 키워드 추출: 문서 안에서 가장 중요하고 자주 등장하는 핵심 단어를 선별하는 기술
- 주제 분류 (토픽 모델링): 여러 문단 속에서 다루고 있는 핵심 주제를 그룹별로 묶어내는 기술

> **[Note]** 방대한 통계 보고서에서 필요한 핵심만 뽑아내기 위해 텍스트마이닝 기법을 사용합니다. 문장을 기본 단위로 쪼개는 형태소 분석, 중요 단어를 찾아내는 키워드 추출, 그리고 보고서의 핵심 주제를 분류하는 기법이 대표적입니다.

### 페이지 17. 정밀한 계산 프로그램 방식과 유연한 AI 생성 방식의 결합

Rule-based 규칙 알고리즘과 LLM 생성형 방식의 하이브리드 비교

수치 정확성
- 정밀 계산 프로그램: 100% 완벽함 (오류 없음)
- 생성형 AI 모델: 계산 시 실수할 가능성 있음
- 하이브리드 적용: 계산은 정밀 프로그램이 담당

문장 표현력
- 정밀 계산 프로그램: 정해진 틀만 사용 (단조로움)
- 생성형 AI 모델: 매끄럽고 다양한 표현 가능
- 하이브리드 적용: 문장 작성은 생성형 AI가 담당

핵심 요약: 수치 오차 절대 방지와 읽기 쉬운 보도자료 완성이라는 정확성과 가독성을 모두 확보

> **[Note]** 보도자료 작성 시스템을 만들 때는 정밀한 계산 프로그램과 생성형 AI의 장점을 조합합니다. 수치 계산과 단위 표기는 오차가 없는 프로그램 방식으로 100% 정확성을 확보하고, 가독성 높은 문장 작성은 생성형 AI를 활용합니다.

### 페이지 18. AI의 글쓰기 원리와 엉뚱한 답(환각 현상)을 내놓는 이유 (1)

LLM의 동작 원리 및 확률적 생성

글쓰기 원리: 정답을 직접 찾는 것이 아니라, 앞 단어들을 바탕으로 가장 어울리는 다음 단어를 확률적으로 이어붙이는 방식

예시 문장

"철수는 어린 시절 바닷가에서 살았다. 그래서 지금도 철수는 [    ] 소리가 들리면 마음이 편안해진다."

후보 단어: 1) 뱃고동 2) 크락션 3) 철도 4) 비행기

> **[Note]** Large Language Model(LLM)의 동작 원리입니다. AI 모델은 사실을 검색하는 것이 아니라, 앞 단어 뒤에 올 가장 어울리는 단어를 확률적으로 연결하여 문장을 만듭니다.

### 페이지 19. AI의 글쓰기 원리와 엉뚱한 답(환각 현상)을 내놓는 이유 (2)

- 환각 원인: 사실 여부보다 자연스러운 문장 만들기를 우선시하다 보니 때때로 그럴듯한 거짓말을 만들어 내는 경우 발생

> **[Note]** 이 때문에 때로는 사실과 다른 거짓 내용을 마치 진실처럼 그럴듯하게 써내는 환각 현상이 발생합니다. 따라서 통계 보도자료를 쓸 때는 검증된 숫자만을 참고 자료로 제공하여 엉뚱한 말이 나오지 않도록 통제해야 합니다.

### 페이지 23. 데이터 보안 등급 분류 및 처리 기준

3단계 보안 등급 구조

- 1등급 (비밀, 대외비): 외부 AI 서비스로 전달 절대 금지
- 2등급 (미공개 통계, 공표 전 엠바고): 데이터가 외부에 누설되어 재학습되지 않도록 안전장치가 갖춰진 전용 통로만 이용
- 3등급 (이미 공개된 통계): 일반적인 개방 데이터를 활용해 AI로 가공

참고 기준

- 통계법 기준: 공표 전 통계(미공개 통계)와 공표된 통계 구분
- 보안업무규정: 1급, 2급, 3급 비밀 및 대외비 분류

> **[Note]** 통계 데이터는 아직 발표되지 않은 공표 전 미공개 통계와 이미 일반에 공개된 공표된 통계로 엄격히 구분됩니다. 특히 공표 전 통계를 AI로 처리할 때는 데이터가 외부에 남아 AI 학습에 재활용되거나 유출되지 않도록 전용 연결 환경을 사용하는 것이 중요합니다. 본 강의에서는 이미 공개된 3등급 자료를 다룹니다.

### 페이지 24. 생성형 AI 활용 시 정보유출 방지 보안 수칙

핵심 보안 수칙 (Zero Data Retention)

1. 일반 개인용 대화 웹 화면 사용 자제: 입력한 대화 내용이 AI 모델의 재학습에 이용될 위험 존재
2. 전용 개발 연결 통로(API) 활용: 입력 데이터가 서버에 저장되지 않고 즉시 삭제되는 데이터 보존 제로(Zero Data Retention) 정책 적용
3. 데이터 전송 시 암호화 통신 적용: 전송 패킷 탈취 방지를 위한 HTTPS 종단간 암호화 적용

> **[Note]** 일반적인 웹 대화창에 통계 데이터를 입력하면 내용이 AI 학습에 이용되어 유출 위험이 있습니다. 따라서 업무용으로는 데이터 보존 제로 정책이 보장된 전용 API 연결 방식을 활용해야 하며, 데이터 전송은 암호화되어야 합니다.

### 페이지 27. 개인정보 자동 가리기(마스킹) 프로그램

파이썬 정규표현식 마스킹 코드

```python
import re

def mask_sensitive_info(text: str) -> str:
    # 주민등록번호 별표 가리기
    text = re.sub(r'\d{6}-[1-4]\d{6}', '******-*******', text)
    # 전화번호 별표 가리기
    text = re.sub(r'01[016789]-\d{3,4}-\d{4}', '010-****-****', text)
    return text
```

> **[Note]** AI에 텍스트를 전송하기 전, 프로그램이 자동으로 개인정보를 별표로 가려주는 전처리 단계를 거치도록 설정합니다. AI에게 개인정보를 삭제해달라고 프롬프트로 지시하기보다 코드로 확실히 전처리하는 것이 안전합니다.

### 페이지 28. 보도자료 작성 전 꼭 확인해야 할 5가지 보안 점검표

보안 점검표 (Checklist)

1. AI 비밀키가 코드 안에 직접 노출되어 있지 않은가
2. 입력 데이터가 외부에 남지 않는 전용 API를 사용하고 있는가
3. 미공개 통계 데이터를 개인 대화형 웹창에 직접 넣지 않았는가
4. 개인정보나 민감한 정보가 별표로 잘 가려졌는가
5. 완성된 글의 숫자를 작성자가 직접 최종 확인하였는가

> **[Note]** AI를 활용해 보도자료를 배포하기 전, 위 5가지 보안 점검표를 확인해야 합니다. 비밀키의 안전한 보관, 전용 연결 통로 사용, 개인정보 가리기, 최종 사람 검수까지 모두 완료되어야 안심하고 배포할 수 있습니다.
