## 1단계. 실제 xlsx 원자료를 처음부터 읽어보기

> 개념 참고: 강의안 소주제 1 (페이지 6~9, `load_input`으로 xlsx/PDF 통합 입력)

지금까지는 2차시에서 손으로 만든 데이터를 계속 이어받았습니다. 이번에는 실제 엑셀 파일([data/raw/온라인쇼핑동향_2026_01.xlsx](../data/raw/온라인쇼핑동향_2026_01.xlsx))을 처음부터 읽는 과정을 직접 확인합니다.

```python
import sys, json
sys.path.insert(0, ".")
from modules.io import load_input

raw = load_input("data/raw/온라인쇼핑동향_2026_01.xlsx")
print(json.dumps(raw, ensure_ascii=False, indent=2))
```

**실제 실행 결과**

```json
{
  "제목": "2026-01 온라인쇼핑 동향",
  "계산지표": {
    "총거래액": 201250,
    "전월대비증감률": 1.5,
    "전년동월대비증감률": 8.7
  },
  "원문": "2026년 1월 온라인쇼핑 거래액은 201,250억 원으로 전월 대비 1.5% 증가하였다. 전년동월대비로는 8.7% 증가한 수치이다. 이는 역대 1월 기준 최대치를 기록한 것이다. 모바일쇼핑 거래액 비중은 전체의 78%를 차지하며 꾸준한 증가세를 보이고 있다."
}
```

**직접 확인할 점 1**: `원문`이 지금까지 이어온 [data/processed/press_data.json](../data/processed/press_data.json)의 `원문`과 완전히 똑같습니다. 이 프로젝트의 샘플 xlsx가 2차시부터 이어온 예제 텍스트와 같은 내용으로 만들어져 있기 때문입니다.

**직접 확인할 점 2 (실제 코드의 사소한 특징)**: `제목`이 "**2026-01** 온라인쇼핑 동향"으로, 지금까지 써온 "**2026년 1월** 온라인쇼핑 동향"과 표기가 다릅니다. 이 xlsx에는 "제목" 열이 따로 없어서, `load_input`이 `f"{row['연월']} 온라인쇼핑 동향"`으로 제목을 자동 생성하는데, 엑셀의 "연월" 열 값이 "2026-01"이기 때문입니다. 실무에서 다른 통계표를 붙일 때 이 줄도 함께 손봐야 하는 부분입니다.

이 xlsx에는 "이력" 시트가 없으므로, `역대최대여부`/`최근3개월증감률`은 이번에는 자동 계산되지 않고 `raw`에 아예 없습니다(있었다면 `derive_history_indicators`가 자동으로 채웠을 것입니다 — 5차시 4단계에서 확인한 것과 같은 함수입니다).

## 2단계. 지금까지 쌓아온 데이터로 계속 진행하기

방금 읽은 `raw`는 아직 정제·NLP·계산 단계를 거치지 않은 "갓 입력된" 데이터입니다. 실제 파이프라인([main.py](../main.py))에서도 `load_input` 다음에는 `clean_and_structure → analyze_document → add_calculated_indicators`가 순서대로 이어집니다. 우리는 2~6차시에서 이미 이 단계들을 직접 밟아 [data/processed/press_data.json](../data/processed/press_data.json)을 완성해 두었으므로, 이번 차시부터는 다시 반복하지 않고 그 결과를 그대로 이어받습니다.

```python
with open("data/processed/press_data.json", encoding="utf-8") as f:
    data = json.load(f)
print(data["문서정보"]["제목"])  # 1단계와 달리 "2026년 1월 온라인쇼핑 동향"
```

## 4단계. 제목·부제·리드문 프롬프트 확인하기 (API 호출 없음)

> 개념 참고: 강의안 소주제 2 (페이지 13~16, 6하원칙 기반 프롬프트 설계)

```python
from modules.write import build_headline_prompt

참고_제목후보 = data.get("요약결과", {}).get("제목후보", [])
prompt = build_headline_prompt(core, data["통계해석결과"]["특이점목록"], 참고_제목후보)
print(prompt)
```

**실제 실행 결과**

```
아래 정보를 바탕으로 다음 3가지를 JSON으로 작성해 주세요.
1) 제목(15자 내외, 핵심 수치 또는 증감 방향 포함)
2) 부제(제목과 중복되지 않는 두 번째 정보, 25자 내외)
3) 리드문(6하원칙에 따라 3~4문장)

숫자는 아래 핵심지표에 주어진 표기(예: 201,250억 원)를 콤마까지 그대로 사용하고,
조 단위로 환산하거나 자릿수를 다시 계산하지 마세요.

핵심지표: 총거래액 201,250억 원, 전월대비증감률 1.5%, 전년동월대비증감률 8.7%
특이사항: 역대 최대치 경신, 전년동월 대비 큰 폭 증가, 최근 3개월 연속 증가세

결과는 반드시 아래 JSON 형식으로만 출력하십시오.
{"제목": "...", "부제": "...", "리드문": "..."}
```

`특이사항`에 5차시에서 계산한 `특이점목록`이 그대로 들어간 것을 확인합니다. (4차시를 건너뛰었다면 `요약결과`가 없어 참고 제목후보 문장이 붙지 않습니다 — 정상입니다.)

## 완성도 점검

1. 제목에 핵심 수치나 증감 방향이 드러나는가
2. 부제가 제목과 중복되지 않는 두 번째 정보를 담고 있는가
3. 리드문이 6하원칙(누가, 언제, 무엇을, 어떻게 등)을 모두 포함하는가
4. 리드문의 모든 숫자가 `verify_numbers` 검증을 통과하였는가
5. `load_input`이 실제 xlsx에서 만든 제목("2026-01 온라인쇼핑 동향")과 지금까지 이어온 표준 데이터의 제목이 왜 다른지 설명할 수 있는가
