## 2. 입력 준비

이 차시는 `mywork/press_data.json`에 **`문서정보`, `계산지표`, `핵심내용`, `원문`** 필드가 있어야 합니다. 앞 차시를 그대로 진행했다면 이미 있고, 앞 차시를 건너뛰었다면 아래 스니펫이 **비어 있는 필드만** 채웁니다(이미 있는 값은 건드리지 않음).

```python
# 입력 Ch03
import json, os

NEED = json.loads("""{
  "문서정보": {
    "제목": "2026년 1월 온라인쇼핑 동향",
    "공표일자": "2026-03-01",
    "자료출처": "공공데이터포털 Open API"
  },
  "계산지표": {
    "총거래액": 201250,
    "전월대비증감률": 1.5,
    "전년동월대비증감률": 8.7
  },
  "핵심내용": [
    "온라인쇼핑 거래액 역대 최대 달성"
  ],
  "원문": "2026년 1월 온라인쇼핑 거래액은 201,250억 원으로 전월 대비 1.5% 증가하였다. 전년동월대비로는 8.7% 증가한 수치이다. 이는 역대 1월 기준 최대치를 기록한 것이다. 모바일쇼핑 거래액 비중은 전체의 78%를 차지하며 꾸준한 증가세를 보이고 있다."
}""")

os.makedirs("mywork", exist_ok=True)
path = "mywork/press_data.json"
data = {}
if os.path.exists(path):
    with open(path, encoding="utf-8") as f:
        data = json.load(f)
added = [k for k in NEED if k not in data]
for k in added:
    data[k] = NEED[k]
with open(path, "w", encoding="utf-8") as f:
    json.dump(data, f, ensure_ascii=False, indent=2)
print("입력 준비 완료 — 새로 채운 필드:", added or "없음(앞 차시 결과를 그대로 사용)")
```

**기대 출력**: `입력 준비 완료 — 새로 채운 필드: ...` (앞 차시를 했다면 `없음(앞 차시 결과를 그대로 사용)`)

## 4. Claude Code 프롬프트

아래 전체를 복사해 Claude Code에 붙여넣고, 파일 쓰기 승인 요청이 뜨면 승인합니다. 생성 위치는 전부 `mywork/` 안입니다(기존 `modules/`는 건드리지 않습니다).

```text
mywork/nlp.py 를 만들어줘. 한국어 보도자료 원문에서 키워드와 주요 문장을 통계·규칙 기반으로 뽑는 모듈이다(생성형 AI 사용 금지). 사용 라이브러리: kiwipiepy, scikit-learn, networkx (이미 설치됨).

모듈 전역:
- Kiwi()는 한 번만 만든다(초기화 비용이 큼).
- ★ 그 Kiwi에 add_user_word(단어, "NNP", 0.0)로 ["온라인쇼핑", "모바일쇼핑", "거래액", "역대급"]을 등록한다. (등록하지 않으면 "온라인쇼핑"이 "온라인"+"쇼핑"으로 쪼개져 핵심 소재가 사라진다)
- STOPWORDS = {"등", "및", "수", "것"}

함수(이름·시그니처 그대로):
1. extract_nouns(text) -> list : 형태소 분석 후 품사 태그가 "NN"으로 시작하는 토큰의 form만 반환.
2. clean_keywords(keyword_scores, top_n=5) -> list[(단어, 점수)] : 불용어와 한 글자 단어를 제외하고 점수 내림차순 상위 top_n개.
3. split_sentences(text) -> list : 마침표·느낌표·물음표 뒤의 공백을 기준으로 문장 분리(정규식 lookbehind), 빈 문장 제거.
4. extract_keywords_tfidf(text, top_n=5) -> list[(단어, 점수)] :
   - ★ 원문은 1건뿐이라 다른 문서와 비교하는 IDF가 무의미하다. 그래서 원문을 문장으로 나눠 "각 문장을 하나의 문서"로 취급한다.
   - 문장별로 명사만 공백으로 이어붙인 문자열 목록(빈 것 제외, 없으면 [] 반환)을 TfidfVectorizer에 넣는다.
   - 단어의 대표 점수 = 그 단어의 문장별 TF-IDF 점수 중 최댓값(열 방향 max). 그 결과를 clean_keywords로 넘겨 반환.
5. extract_main_sentences(sentences, ratio=0.5) -> list : TextRank
   - 문장이 1개 이하면 그대로 반환.
   - 문장별 명사 문자열(명사가 없으면 문장 원문)을 TF-IDF 벡터화 → 코사인 유사도 행렬.
   - ★ 유사도 행렬의 대각선(자기 자신과의 유사도 1.0)은 반드시 0으로 만든다(안 그러면 self-loop가 점수를 왜곡한다).
   - networkx.from_numpy_array로 그래프를 만들고 pagerank 점수를 구한다.
   - 상위 max(1, round(문장수*ratio))개를 뽑되, ★ 반환은 원문에 등장한 순서로 정렬하고 문장을 새로 쓰거나 고치지 않고 원문 그대로 돌려준다(원문과 대조 검증이 가능하고, 이 단계에서는 환각이 생길 수 없다).
6. filter_sentences_by_keywords(sentences, keywords) -> list : 키워드 중 하나라도 문장에 포함되면 남긴다.
7. analyze_document(raw_text, standard_data) -> dict : 위 함수를 조합해 standard_data["NLP분석결과"] = {"핵심키워드": [단어 목록], "주요문장": [최종 필터를 통과한 문장 목록]} 을 채우고 standard_data를 반환.
```

**프롬프트에 꼭 들어간 것과, 빠지면 생기는 문제**

| 프롬프트에 꼭 들어간 것 | 빠지면 생기는 문제 |
| --- | --- |
| Kiwi 사용자 사전 등록 | "온라인쇼핑"이 둘로 쪼개져 키워드에서 사라짐(실제 발생, 3차 세션) |
| 문장 단위 코퍼스 TF-IDF | 문서 1건이면 IDF가 무의미해 모든 단어 점수가 같아짐 |
| 대각선 0 | 자기 자신과의 유사도가 PageRank를 왜곡 |
| 원문 그대로·원문 순서 반환 | 새 문장이 섞이면 환각 검증이 불가능해짐 |

## 7. 함정 관찰 (2분) — "거래액"은 왜 키워드에서 빠졌을까

이 차시에서 프롬프트의 ★ 항목이 왜 필요한지 눈으로 확인합니다. `check.py`로 저장해 실행합니다.

```python
# 관찰 Ch03
import sys, json
sys.path.insert(0, ".")
from mywork.nlp import split_sentences, extract_nouns, extract_keywords_tfidf

with open("mywork/press_data.json", encoding="utf-8") as f:
    text = json.load(f)["원문"]
for i, s in enumerate(split_sentences(text), 1):
    print(i, extract_nouns(s))
for w, sc in extract_keywords_tfidf(text, top_n=8):
    print(f"{w}\t{sc:.3f}")
```

**예시 출력**(생성된 코드에 따라 표현은 조금 다를 수 있습니다)

```text
1 ['년', '월', '온라인쇼핑', '거래액', '원', '전월', '대비', '증가']
2 ['전년', '동월', '대비', '증가', '수치']
3 ['역대', '월', '기준', '최대', '기록', '것']
4 ['모바일쇼핑', '거래액', '비중', '전체', '차지', '증가세']
온라인쇼핑	0.509
전월	0.509
기록	0.500
기준	0.500
역대	0.500
최대	0.500
동월	0.485
수치	0.485
```

**무엇을 볼 것인가**

- `거래액`은 1번·4번 문장에 나오는데도 점수 상위 8개에 없습니다. 문장 하나하나를 독립된 문서로 취급하기 때문에, 짧고 다른 문장과 겹치지 않는 3번 문장의 단어(기록·기준·역대·최대)가 오히려 높게 나옵니다.
- 이것이 "원문이 1건뿐일 때 TF-IDF의 한계"입니다. 그래서 이 결과는 **참고용**이고, 사실 확정은 5차시의 계산이 맡습니다.
- 점수의 소수점 값은 라이브러리 버전에 따라 조금 달라질 수 있습니다. 단어 순서가 대체로 같으면 정상입니다.

## 9. 폴백 — 4:00까지 안 되면

생성이 끝나지 않거나 검증이 끝내 통과하지 않으면, 기존 파일을 복사해 다음으로 넘어갑니다(PowerShell, 프로젝트 루트).

```powershell
New-Item mywork\__init__.py -ItemType File -Force
Copy-Item modules\nlp.py mywork\nlp.py

# 복사한 파일이 mywork의 다른 모듈을 불러오도록 import 경로를 바꿉니다 (modules. -> mywork.)
Get-ChildItem mywork\*.py | ForEach-Object {
    (Get-Content $_.FullName -Raw -Encoding UTF8) -replace 'from modules\.io','from mywork.data_io' -replace 'from modules\.(?!export)','from mywork.' | Set-Content $_.FullName -Encoding UTF8
}
```

복사한 기존 파일도 그대로 검증을 통과해야 합니다.

위 명령의 마지막 부분이 복사한 파일의 import 경로를 `modules.`에서 `mywork.`로 바꿉니다(그래야 복사한 파일이 여러분이 만든 `mywork/write.py` 등을 함께 씁니다. `main.py`의 `modules.export`만 그대로 남습니다). 모든 명령은 **프로젝트 루트에서 실행**하고, 복사 후에는 6절 검증만 다시 실행합니다.
