# Ch 07 10분 실습 — xlsx 입력과 헤드라인

> **이 문서 하나만 보고 진행할 수 있습니다.** 실행할 명령, 붙여넣을 프롬프트, 검증 코드, CLAUDE.md 수정 내용, 기대 결과, 실패했을 때의 대처까지 모두 이 안에 있습니다.
> 원리는 이렇습니다: 미리 만들어진 코드를 실행하는 대신, **Claude Code에게 프롬프트를 주어 같은 기능의 코드를 직접 만들게** 하고, 짧은 검증 코드로 결과를 확인합니다.

| 항목 | 내용 |

| 시각 | 할 일 |

## 1. 시작 전 체크리스트 (1분)

1. 프로젝트 루트(`main.py`, `modules/`가 있는 폴더)에서 PowerShell을 엽니다.
2. 가상환경을 켭니다.

```powershell
myvenv\Scripts\Activate.ps1
$env:PYTHONUTF8 = "1"
```

3. 이 차시에 필요한 패키지가 설치되어 있는지 확인합니다(`OK`가 나오면 됩니다).

```powershell
python -c "import pandas, openpyxl, pdfplumber, anthropic; print('OK')"
```

   오류가 나면 `pip install -r requirements.txt` 를 실행합니다.

4. **API 키**: 선택 단계에서만 필요. 필요한 경우 프로젝트 루트의 `.env` 파일에 `ANTHROPIC_API_KEY=발급받은키` 한 줄이 있어야 합니다.
5. **검증 스니펫 실행 방법**: 이 문서의 `검증`·`관찰`·`입력` 코드는 다음 방법으로 실행합니다.
   - 프로젝트 루트에 `check.py`라는 새 파일을 만들고, 코드를 붙여넣어 저장한 뒤 `python check.py` 를 실행합니다. (다른 코드를 실행할 때는 같은 파일을 덮어씁니다. 실습이 끝나면 `check.py`는 지워도 됩니다.)
6. Claude Code는 **프로젝트 루트에서** 시작합니다(터미널에서 `claude`, 또는 데스크톱 앱의 Code 탭에서 이 프로젝트 폴더를 엽니다). CLAUDE.md는 세션 시작 때 읽히므로 3절을 마친 뒤 **새 세션**으로 시작합니다.

## 2. 입력 준비

이 차시는 `mywork/press_data.json`에 **`문서정보`, `계산지표`, `핵심내용`, `원문`, `통계해석결과`** 필드가 있어야 합니다. 앞 차시를 그대로 진행했다면 이미 있고, 앞 차시를 건너뛰었다면 아래 스니펫이 **비어 있는 필드만** 채웁니다(이미 있는 값은 건드리지 않음).

```python
# 입력 Ch07
import json, os

NEED = json.loads("""{
  "문서정보": {
    "제목": "2026년 1월 온라인쇼핑 동향",
    "공표일자": "2026-03-01",
    "자료출처": "공공데이터포털 Open API"
  },
  "계산지표": {
    "총거래액": 201250,
    "전월대비증감률": 1.5,
    "전년동월대비증감률": 8.7
  },
  "핵심내용": [
    "온라인쇼핑 거래액 역대 최대 달성"
  ],
  "원문": "2026년 1월 온라인쇼핑 거래액은 201,250억 원으로 전월 대비 1.5% 증가하였다. 전년동월대비로는 8.7% 증가한 수치이다. 이는 역대 1월 기준 최대치를 기록한 것이다. 모바일쇼핑 거래액 비중은 전체의 78%를 차지하며 꾸준한 증가세를 보이고 있다.",
  "통계해석결과": {
    "특이점목록": [
      "역대 최대치 경신",
      "전년동월 대비 큰 폭 증가",
      "최근 3개월 연속 증가세"
    ],
    "해석문장": [
      "온라인쇼핑 거래액은 201,250억 원으로 역대 최대치를 기록하였다."
    ]
  }
}""")

os.makedirs("mywork", exist_ok=True)
path = "mywork/press_data.json"
data = {}
if os.path.exists(path):
    with open(path, encoding="utf-8") as f:
        data = json.load(f)
added = [k for k in NEED if k not in data]
for k in added:
    data[k] = NEED[k]
with open(path, "w", encoding="utf-8") as f:
    json.dump(data, f, ensure_ascii=False, indent=2)
print("입력 준비 완료 — 새로 채운 필드:", added or "없음(앞 차시 결과를 그대로 사용)")
```

**기대 출력**: `입력 준비 완료 — 새로 채운 필드: ...` (앞 차시를 했다면 `없음(앞 차시 결과를 그대로 사용)`)

**이전 차시 파일**: 이 차시의 코드는 `mywork/config.py`(2차시), `mywork/stats.py`(5차시), `mywork/write.py`(4차시)를 import 하거나 그 파일에 이어서 함수를 추가합니다. 파일이 있는지 `dir mywork\*.py`로 확인하세요.

앞 차시를 건너뛰어 파일이 없다면 아래로 기존 파일을 복사합니다(프로젝트 루트에서 실행).

```powershell
New-Item mywork\__init__.py -ItemType File -Force
Copy-Item modules\config.py mywork\config.py
Copy-Item modules\stats.py mywork\stats.py
Copy-Item modules\write.py mywork\write.py
```

> 이 차시는 앞 차시에서 만든 `write.py`에 함수를 **추가**하는 차시입니다. 파일이 없어 위처럼 기존 파일을 복사했다면 그 안에 이 차시의 함수가 이미 들어 있으므로, **4절 프롬프트는 건너뛰고 6절 검증만** 진행하세요.

## 4. Claude Code 프롬프트

아래 전체를 복사해 Claude Code에 붙여넣고, 파일 쓰기 승인 요청이 뜨면 승인합니다. 생성 위치는 전부 `mywork/` 안입니다(기존 `modules/`는 건드리지 않습니다).

```text
[mywork/data_io.py]  (주의: 파일 이름을 io.py로 하면 파이썬 표준 라이브러리 io와 충돌할 수 있어 data_io.py로 만든다)
필요 import: json, os, pandas, pdfplumber, mywork.config의 REQUIRED_FIELDS, mywork.stats의 derive_history_indicators

load_input(파일경로) -> dict
- 확장자(소문자)로 분기한다. 지원하지 않는 확장자면 ValueError(f"지원하지 않는 파일 형식입니다: {확장자}").
- ".xlsx": pandas.ExcelFile로 열어 첫 시트의 첫 행을 dict로 읽는다.
  raw = {"제목": 행의 "제목" 값이 있으면 그것, 없으면 f"{행의 연월} 온라인쇼핑 동향",
         "계산지표": {필드: 행[필드] for 필드 in REQUIRED_FIELDS},
         "원문": 행의 "원문"(없으면 "")}
  * ★ "품목별지표" 열이 있으면 값이 str일 때 json.loads로 파싱해 raw["품목별지표"]에 넣는다(엑셀 셀에는 리스트를 못 넣어 JSON 문자열로 저장돼 있다).
  * "이력" 시트(열: 연월, 총거래액)가 있으면: history = [{"연월": str(연월), "값": 총거래액}, ...]. raw["월별이력"] = history + [이번 달 {"연월","값"}]. derive_history_indicators(history, 이번 연월, 이번 총거래액)로 "역대최대여부"와 "최근3개월증감률"을 계산해 raw에 넣는다(이미 있으면 덮어쓰지 않는다).
  * 행에 "역대최대여부"/"최근3개월증감률" 열이 있으면 그 값이 우선한다(bool()로 변환 / str이면 json.loads).
- ".pdf": pdfplumber로 모든 페이지의 extract_text()(None이면 "")를 "\n"으로 이어붙여 {"원문": 전체 텍스트} 반환.

save_final_document(data) : output/ 폴더를 만들고(exist_ok) output/{data["문서정보"]["제목"]}.txt 에 data["최종본"]을 utf-8로 저장.

[mywork/write.py 에 함수 추가]  (4차시에 만든 파일에 이어서 추가. 기존 함수는 수정하지 말 것)
필요 import 추가: mywork.config의 REQUIRED_FIELDS, INDICATOR_UNITS
- select_core_indicators(계산지표: dict) -> dict : REQUIRED_FIELDS에 있는 키만 남긴 dict.
- build_headline_prompt(core, special_points, 참고_제목후보=None) -> str
  * ★ 핵심지표 문장은 "총거래액 201,250억 원, 전월대비증감률 1.5%, 전년동월대비증감률 8.7%"처럼 값에 천 단위 콤마를 넣고 INDICATOR_UNITS의 단위를 값 바로 뒤에 붙인다. (콤마 없이 주면 LLM이 "20조 1,250억원"으로 재환산하거나 "201250원"으로 써서 9차시 표기 검사에 걸린다)
  * ★ 프롬프트에 "숫자는 핵심지표에 주어진 표기를 콤마까지 그대로 쓰고, 조 단위 환산이나 자릿수 재계산을 하지 말 것"을 명시한다.
  * 요청 항목: 1) 제목(15자 내외, 핵심 수치 또는 증감 방향 포함) 2) 부제(제목과 중복되지 않는 두 번째 정보, 25자 내외) 3) 리드문(6하원칙에 따라 3~4문장). 과장된 수식어는 금지.
  * "특이사항:" 줄에 special_points를 ", "로 이어붙여 넣는다.
  * 참고_제목후보가 있으면 "참고(4차시 요약 단계에서 생성된 제목 아이디어, 그대로 채택하지 않아도 됨): ..." 한 줄을 추가한다(새 숫자를 들여오지 않는 표현 참고용).
  * 결과는 {"제목": "...", "부제": "...", "리드문": "..."} JSON으로만 출력하라고 지시.
- generate_headline_set(data) -> dict : select_core_indicators(data["계산지표"]), data["통계해석결과"]["특이점목록"], data.get("요약결과", {}).get("제목후보", [])로 프롬프트를 만들어 client.messages.create(model=MODEL_NAME, max_tokens=600, system="통계청 보도자료 작성 담당자로서 제공된 사실만 사용하여 JSON 형식으로 답하십시오.")를 호출하고 parse_json_response로 반환.
```

**프롬프트에 꼭 들어간 것과, 빠지면 생기는 문제**

| 프롬프트에 꼭 들어간 것 | 빠지면 생기는 문제 |
| --- | --- |
| 핵심지표에 콤마·단위 포함 | LLM이 숫자를 재환산·콤마 누락 → 9차시 표기 검사 실패 |
| `품목별지표` JSON 문자열 파싱 | xlsx의 리스트 열이 문자열 그대로 남아 이후 단계에서 오류 |
| 이력 시트 → `derive_history_indicators` | 담당자가 "역대 최대" 여부를 손으로 조사해야 함 |
| 참고 제목후보(새 숫자 없이) | 4차시 요약 결과가 파이프라인에서 쓰이지 않는 죽은 코드가 됨 |
| 파일명 `data_io.py` | 표준 라이브러리 `io`를 가려 pandas 등이 깨질 수 있음 |

## 7. 함정 관찰 (2분) — 프롬프트 속 숫자 표기(콤마·단위)

이 차시에서 프롬프트의 ★ 항목이 왜 필요한지 눈으로 확인합니다. `check.py`로 저장해 실행합니다.

```python
# 관찰 Ch07
import sys
sys.path.insert(0, ".")
from mywork.write import build_headline_prompt

p = build_headline_prompt({"총거래액": 201250, "전월대비증감률": 1.5}, ["역대 최대치 경신"])
print([line for line in p.splitlines() if line.startswith("핵심지표")])
```

**예시 출력**(생성된 코드에 따라 표현은 조금 다를 수 있습니다)

```text
['핵심지표: 총거래액 201,250억 원, 전월대비증감률 1.5%']
```

**무엇을 볼 것인가**

- LLM에게 주는 숫자가 `201,250억 원`(콤마+단위)으로 미리 포맷되어 있습니다. 콤마 없이 `201250`만 주면 LLM이 "20조 1,250억원"처럼 환산하거나 콤마 없이 써서, 9차시 표기 검사·수치 검증에 걸립니다.
- 실습 검증에서 읽은 `load_input` 결과의 제목이 `2026-01 온라인쇼핑 동향`(하이픈)이었던 것도 기억해 두세요. 엑셀의 `연월` 값이 `2026-01`이라 그렇게 만들어진 것입니다.

## 9. 폴백 — 4:00까지 안 되면

생성이 끝나지 않거나 검증이 끝내 통과하지 않으면, 기존 파일을 복사해 다음으로 넘어갑니다(PowerShell, 프로젝트 루트).

```powershell
New-Item mywork\__init__.py -ItemType File -Force
Copy-Item modules\config.py mywork\config.py
Copy-Item modules\stats.py mywork\stats.py
Copy-Item modules\write.py mywork\write.py
Copy-Item modules\io.py mywork\data_io.py

# 복사한 파일이 mywork의 다른 모듈을 불러오도록 import 경로를 바꿉니다 (modules. -> mywork.)
Get-ChildItem mywork\*.py | ForEach-Object {
    (Get-Content $_.FullName -Raw -Encoding UTF8) -replace 'from modules\.io','from mywork.data_io' -replace 'from modules\.(?!export)','from mywork.' | Set-Content $_.FullName -Encoding UTF8
}
```

복사한 기존 파일도 그대로 검증을 통과해야 합니다.

위 명령의 마지막 부분이 복사한 파일의 import 경로를 `modules.`에서 `mywork.`로 바꿉니다(그래야 복사한 파일이 여러분이 만든 `mywork/write.py` 등을 함께 씁니다. `main.py`의 `modules.export`만 그대로 남습니다). 모든 명령은 **프로젝트 루트에서 실행**하고, 복사 후에는 6절 검증만 다시 실행합니다.

## 10. 문제 해결

| 증상 | 원인 | 조치 |
| --- | --- | --- |
| `FileNotFoundError: data/raw/...xlsx` | 샘플 xlsx가 없음 | `python scripts/make_sample_excel.py` 와 `python scripts/make_sample_excel_full.py` 실행 |
| 표준 라이브러리 오류(`io` 관련) | 파일명을 `io.py`로 만들었음 | `mywork/data_io.py`로 이름을 바꾸고 import도 수정 |
| `ModuleNotFoundError: No module named 'mywork'` | 프로젝트 루트가 아닌 곳에서 실행했거나 `mywork/__init__.py`가 없음 | 프로젝트 루트로 이동(`cd`) 후 다시 실행. `New-Item mywork\__init__.py -ItemType File -Force` |
| 한글이 `???`·깨진 글자로 출력 | PowerShell 기본 코드페이지(cp949) | `$env:PYTHONUTF8 = "1"` 후 다시 실행 |
| `ModuleNotFoundError: No module named 'pandas'` 등 패키지 없음 | 가상환경 미활성화 또는 미설치 | `myvenv\Scripts\Activate.ps1` 후 `pip install -r requirements.txt` |
| Claude Code가 `modules/`를 열어 보거나 복사해서 만듦 | CLAUDE.md 규칙이 적용되지 않음 | 3절을 다시 확인하고 **새 세션**으로 시작. 이미 만들어졌다면 그 파일을 지우고 프롬프트를 다시 붙여넣기 |
| `AssertionError`가 나옴 | 생성 코드가 프롬프트의 ★ 항목 중 일부를 빠뜨림 | 오류 메시지와 `check.py` 결과를 Claude Code에 **그대로 붙여** 수정 요청(1회). 그래도 안 되면 폴백 |
| 생성이 4분 넘게 끝나지 않음 | 생성 지연 또는 프롬프트 오해 | 중단하고 폴백(9절)으로 진행. 검증 스니펫은 그대로 실행 |
