## 2. 입력 준비

이 차시는 `mywork/press_data.json`에 **`문서정보`, `계산지표`, `핵심내용`, `원문`** 필드가 있어야 합니다. 앞 차시를 그대로 진행했다면 이미 있고, 앞 차시를 건너뛰었다면 아래 스니펫이 **비어 있는 필드만** 채웁니다(이미 있는 값은 건드리지 않음).

```python
# 입력 Ch06
import json, os

NEED = json.loads("""{
  "문서정보": {
    "제목": "2026년 1월 온라인쇼핑 동향",
    "공표일자": "2026-03-01",
    "자료출처": "공공데이터포털 Open API"
  },
  "계산지표": {
    "총거래액": 201250,
    "전월대비증감률": 1.5,
    "전년동월대비증감률": 8.7
  },
  "핵심내용": [
    "온라인쇼핑 거래액 역대 최대 달성"
  ],
  "원문": "2026년 1월 온라인쇼핑 거래액은 201,250억 원으로 전월 대비 1.5% 증가하였다. 전년동월대비로는 8.7% 증가한 수치이다. 이는 역대 1월 기준 최대치를 기록한 것이다. 모바일쇼핑 거래액 비중은 전체의 78%를 차지하며 꾸준한 증가세를 보이고 있다."
}""")

os.makedirs("mywork", exist_ok=True)
path = "mywork/press_data.json"
data = {}
if os.path.exists(path):
    with open(path, encoding="utf-8") as f:
        data = json.load(f)
added = [k for k in NEED if k not in data]
for k in added:
    data[k] = NEED[k]
with open(path, "w", encoding="utf-8") as f:
    json.dump(data, f, ensure_ascii=False, indent=2)
print("입력 준비 완료 — 새로 채운 필드:", added or "없음(앞 차시 결과를 그대로 사용)")
```

**기대 출력**: `입력 준비 완료 — 새로 채운 필드: ...` (앞 차시를 했다면 `없음(앞 차시 결과를 그대로 사용)`)

**이전 차시 파일**: 이 차시의 코드는 `mywork/config.py`(2차시)를 import 하거나 그 파일에 이어서 함수를 추가합니다. 파일이 있는지 `dir mywork\*.py`로 확인하세요.

앞 차시를 건너뛰어 파일이 없다면 아래로 기존 파일을 복사합니다(프로젝트 루트에서 실행).

```powershell
New-Item mywork\__init__.py -ItemType File -Force
Copy-Item modules\config.py mywork\config.py
```

### 3-1. 기존 규칙 3줄 수정

## 4. Claude Code 프롬프트

아래 전체를 복사해 Claude Code에 붙여넣고, 파일 쓰기 승인 요청이 뜨면 승인합니다. 생성 위치는 전부 `mywork/` 안입니다(기존 `modules/`는 건드리지 않습니다).

```text
mywork/charts.py 를 만들어줘. matplotlib, pandas 사용.

- ★ 모듈 맨 위에서 pyplot을 import 하기 전에 matplotlib.use("Agg")를 호출한다(화면 없이 파일로만 저장. 일부 Windows 환경에서 기본 백엔드의 Tk 오류를 피한다).
- 한글 폰트: plt.rc("font", family="Malgun Gothic") (Windows 기준)
- mywork/config.py의 PRIMARY_INDICATOR를 import 한다.

1. generate_chart_description(chart_type, data: DataFrame, label=None) -> str
   - "bar": data를 "당월거래액" 내림차순으로 정렬해 1위·2위·꼴찌를 뽑아
     "{1위 품목}이 {값:,}억 원으로 가장 높았으며, {2위 품목}이 {값:,}억 원으로 그 뒤를 이었다. 반면 {꼴찌 품목}은 {값:,}억 원으로 가장 낮은 수준을 보였다."
   - "pie": "비중" 내림차순 상위 3개로
     "품목별 비중을 살펴보면 {1위}이 전체의 {비중}%로 가장 큰 비중을 차지하였으며, {2위}({비중}%), {3위}({비중}%)이 그 뒤를 이었다."
   - "line": "연월" 오름차순, 값 열 이름은 "거래액". 시작 값보다 종료 값이 크면 "증가", 아니면 "감소"로
     "{주어}은 {시작 연월}부터 {종료 연월}까지 {증가|감소}세를 보이고 있으며, {종료 연월}에 {값:,}억 원을 기록하였다."
     ★ 주어는 label 인자로 받고(없으면 PRIMARY_INDICATOR) 반드시 문장 맨 앞에 명시한다. 주어가 없는 문장을 8차시에서 LLM이 본문으로 확장하면 "이게 무엇에 대한 추세지?"를 추측하다가 전혀 엉뚱한 주제를 지어낸다.
   - 그 외 유형은 "" 반환. (조사가 어색해도 이번에는 템플릿 그대로 둔다)
2. build_visual_descriptions(data: dict) -> list[dict]
   - ★ 먼저 os.makedirs("images", exist_ok=True) (폴더가 없으면 savefig가 실패한다)
   - 제목 = data["문서정보"]["제목"]
   - data에 "품목별지표"(dict 리스트: 품목·당월거래액·비중 등)가 있으면: 한 장의 그림(1행 2열)에 왼쪽 막대(품목 vs 당월거래액), 오른쪽 원형(비중, autopct="%.1f%%")을 그려 f"images/{제목}_품목별.png"로 저장(dpi=150, bbox_inches="tight", 저장 후 plt.close). 결과에 두 항목 추가:
     {"소주제": "품목별 동향", "그래프유형": "막대그래프", "이미지경로": 경로, "설명문": bar 설명}
     {"소주제": "품목별 비중", "그래프유형": "원형그래프", "이미지경로": 같은 경로, "설명문": pie 설명}
   - data에 "월별이력"([{"연월","값"}])이 있고 비어 있지 않으면: 꺾은선 그래프(marker="o")를 f"images/{제목}_추이.png"로 저장하고 {"소주제": "시계열 동향", "그래프유형": "꺾은선그래프", "이미지경로": 경로, "설명문": line 설명(label=PRIMARY_INDICATOR)} 추가.
   - 두 조건은 서로 독립이다(둘 중 하나만 있어도 동작).
   - ★ 모든 항목에 "소주제" 필드를 반드시 넣는다(8차시가 이 필드로 본문 단락의 주제를 정한다).
   - 반환은 위 dict들의 리스트.
```

**프롬프트에 꼭 들어간 것과, 빠지면 생기는 문제**

| 프롬프트에 꼭 들어간 것 | 빠지면 생기는 문제 |
| --- | --- |
| `matplotlib.use("Agg")` | `savefig`에서 간헐적 `_tkinter.TclError`(이 프로젝트에서 실제로 겪은 환경 문제) |
| `images/` 폴더 먼저 생성 | 폴더가 없으면 저장 실패 |
| 꺾은선 설명문의 주어(label) | 8차시 LLM이 엉뚱한 주제를 지어내는 환각 |
| `소주제` 필드 | 8차시 본문 단락의 주제를 결정할 수 없음 |

## 9. 폴백 — 4:00까지 안 되면

생성이 끝나지 않거나 검증이 끝내 통과하지 않으면, 기존 파일을 복사해 다음으로 넘어갑니다(PowerShell, 프로젝트 루트).

```powershell
New-Item mywork\__init__.py -ItemType File -Force
Copy-Item modules\config.py mywork\config.py
Copy-Item modules\charts.py mywork\charts.py

# 복사한 파일이 mywork의 다른 모듈을 불러오도록 import 경로를 바꿉니다 (modules. -> mywork.)
Get-ChildItem mywork\*.py | ForEach-Object {
    (Get-Content $_.FullName -Raw -Encoding UTF8) -replace 'from modules\.io','from mywork.data_io' -replace 'from modules\.(?!export)','from mywork.' | Set-Content $_.FullName -Encoding UTF8
}
```

복사한 기존 파일도 그대로 검증을 통과해야 합니다.

위 명령의 마지막 부분이 복사한 파일의 import 경로를 `modules.`에서 `mywork.`로 바꿉니다(그래야 복사한 파일이 여러분이 만든 `mywork/write.py` 등을 함께 씁니다. `main.py`의 `modules.export`만 그대로 남습니다). 모든 명령은 **프로젝트 루트에서 실행**하고, 복사 후에는 6절 검증만 다시 실행합니다.

## 10. 문제 해결

| 증상 | 원인 | 조치 |
| --- | --- | --- |
| 그림에 한글이 네모로 나옴 | `Malgun Gothic` 폰트가 없는 환경 | Windows 이외 환경에서는 설치된 한글 폰트로 바꾸도록 수정 요청 |
| `_tkinter.TclError` | matplotlib 기본 백엔드 문제 | `pyplot` import 전에 `matplotlib.use("Agg")`가 있는지 확인 |
| `ModuleNotFoundError: No module named 'mywork'` | 프로젝트 루트가 아닌 곳에서 실행했거나 `mywork/__init__.py`가 없음 | 프로젝트 루트로 이동(`cd`) 후 다시 실행. `New-Item mywork\__init__.py -ItemType File -Force` |
| 한글이 `???`·깨진 글자로 출력 | PowerShell 기본 코드페이지(cp949) | `$env:PYTHONUTF8 = "1"` 후 다시 실행 |
| `ModuleNotFoundError: No module named 'pandas'` 등 패키지 없음 | 가상환경 미활성화 또는 미설치 | `myvenv\Scripts\Activate.ps1` 후 `pip install -r requirements.txt` |
| Claude Code가 `modules/`를 열어 보거나 복사해서 만듦 | CLAUDE.md 규칙이 적용되지 않음 | 3절을 다시 확인하고 **새 세션**으로 시작. 이미 만들어졌다면 그 파일을 지우고 프롬프트를 다시 붙여넣기 |
| `AssertionError`가 나옴 | 생성 코드가 프롬프트의 ★ 항목 중 일부를 빠뜨림 | 오류 메시지와 `check.py` 결과를 Claude Code에 **그대로 붙여** 수정 요청(1회). 그래도 안 되면 폴백 |
| 생성이 4분 넘게 끝나지 않음 | 생성 지연 또는 프롬프트 오해 | 중단하고 폴백(9절)으로 진행. 검증 스니펫은 그대로 실행 |
