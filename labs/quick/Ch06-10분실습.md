## 4. Claude Code 프롬프트

Claude Code를 **새로 시작**(`claude`)하고 아래를 붙여넣습니다.

```text
mywork/charts.py 를 만들어줘. (matplotlib, pandas 사용)

- 맨 위에서 matplotlib.use("Agg") 를 pyplot import보다 먼저 호출한다.
- plt.rc("font", family="Malgun Gothic"), plt.rc("axes", unicode_minus=False)

generate_chart_description(chart_type: str, data: pd.DataFrame, label: str = None) -> str
- "bar": 당월거래액 내림차순으로 1위·2위·최하위를 뽑아
  "{1위 품목}이 {값}억 원으로 가장 높았으며, {2위 품목}이 {값}억 원으로 그 뒤를 이었다. 반면 {최하위 품목}은 {값}억 원으로 가장 낮은 수준을 보였다."
- "pie": 비중 내림차순 상위 3개로
  "품목별 비중을 살펴보면 {1위}이 전체의 {비중}%로 가장 큰 비중을 차지하였으며, {2위}({비중}%), {3위}({비중}%)이 그 뒤를 이었다."
- "line": 연월 오름차순으로 정렬(인덱스 재설정)한 뒤 첫 값과 마지막 값으로 추세방향("증가"/"감소")을 정한다.
  ★ 주어는 label, 없으면 "총거래액".
  변곡점 = 거래액.diff()와 그 다음 값의 곱이 음수인 행(증감 방향이 바뀌는 달)이며, 있으면 마지막 변곡점을 언급한다.
  "{주어}은 {시작 연월}부터 {끝 연월}까지 {추세방향}세를 보이고 있으며, [{마지막 변곡점 연월}에 방향이 바뀐 뒤 ]{끝 연월}에 {마지막 값}억 원을 기록하였다."
- 금액은 int로 바꿔 천 단위 콤마를 넣는다. 비중은 값 그대로. 그 밖의 유형은 ValueError.

generate_table_description(data: pd.DataFrame) -> str
- 순위순으로 "{순위}위 {품목}({비중}%)"를 ", "로 이어 "품목별 순위는 … 순으로 나타났다." 문장을 만든다.

build_visual_descriptions(data: dict) -> list
- images 폴더를 만든다. 제목 = 문서정보["제목"], 지표명 = 문서정보.get("지표명", "거래액"), 출처 = 문서정보.get("자료출처", "국가데이터처").
- 품목별지표가 있으면: 한 그림(1행 2열)에 왼쪽 막대(품목별 당월거래액, y축 "거래액(억 원)"),
  오른쪽 원형(비중, autopct="%.1f%%")을 그린다. 각 제목은 "{제목} 품목별 거래액", "{제목} 품목별 비중(%)".
  그림 오른쪽 아래에 "자료: {출처}"를 넣는다(눈금과 겹치지 않게). images/품목별_거래액_비중.png 로 저장(dpi=150, bbox_inches="tight") 후 plt.close.
  결과에 두 항목을 넣는다(같은 이미지 경로):
  {"소주제": "품목별 동향", "그래프유형": "막대그래프", "이미지경로": ..., "설명문": bar 설명문}
  {"소주제": "품목별 비중", "그래프유형": "원형그래프", "이미지경로": ..., "설명문": pie 설명문}
- 월별이력이 있으면: "값" 열을 "거래액"으로 바꾸고 연월순 정렬, 꺾은선(marker="o")을 그린다.
  제목 "{제목} 월별 추이", y축 "거래액(억 원)", x축 눈금 45도 회전, x축 이름 자리에 "자료: {출처}"(오른쪽 정렬).
  images/월별_거래액_추이.png 로 저장 후 plt.close.
  {"소주제": "시계열 동향", "그래프유형": "꺾은선그래프", "이미지경로": ..., "설명문": line 설명문(★ label=지표명)}
- ★ 두 조건은 서로 독립이다(품목별지표만 있어도, 월별이력만 있어도 동작). 결과 목록을 돌려준다.
```

**프롬프트의 ★ 항목과, 빠지면 생기는 문제**

| ★ 항목 | 빠지면 생기는 문제 |
| --- | --- |
| `matplotlib.use("Agg")`를 pyplot보다 먼저 | 창을 띄우려다 멈추거나 오류가 나는 환경이 있음(파일 저장만 필요) |
| 꺾은선 주어 = label(지표명) | "2025-01부터 증가세를 보이고…"처럼 주어가 없으면 8차시에서 AI가 무엇에 대한 추세인지 추측하다 엉뚱한 내용을 지어냄(슬라이드 15 노트) |
| 막대·원형과 꺾은선 조건을 독립으로 | 품목별 자료가 없는 통계에서 월별 추이 그래프까지 빠짐(10차시 슬라이드 9) |
| `소주제` 포함 | 8차시가 설명문을 어떤 단락으로 확장할지 알 수 없음(슬라이드 19 노트) |

## 6. 검증 (핵심)

```python
# 검증 Ch06
import sys, os, json
import pandas as pd
sys.path.insert(0, ".")
from mywork.charts import generate_chart_description, generate_table_description, build_visual_descriptions

with open("mywork/press_data.json", encoding="utf-8") as f:
    data = json.load(f)
items = pd.DataFrame(data["품목별지표"])
history = pd.DataFrame(data["월별이력"]).rename(columns={"값": "거래액"})

bar = generate_chart_description("bar", items)
pie = generate_chart_description("pie", items)
line = generate_chart_description("line", history, label="온라인쇼핑 거래액")
print("막대:", bar)
print("원형:", pie)
print("꺾은선:", line)
assert bar.startswith("의류") and "65,000억 원" in bar and "52,000억 원" in bar and "10,000억 원" in bar
assert "32.3%" in pie and "(25.8%)" in pie and "(23.9%)" in pie
assert line.startswith("온라인쇼핑 거래액은 2025-01부터 2026-01까지 증가세"), "꺾은선 주어·추세 확인"
assert "2025-09에 방향이 바뀐 뒤" in line and line.endswith("201,250억 원을 기록하였다.")
assert generate_chart_description("line", history).startswith("총거래액은"), "label이 없을 때 기본 주어"
assert generate_table_description(items).startswith("품목별 순위는 1위 의류(32.3%), 2위 가전(25.8%)")

visuals = build_visual_descriptions(data)
assert [v["소주제"] for v in visuals] == ["품목별 동향", "품목별 비중", "시계열 동향"]
assert all(set(v) == {"소주제", "그래프유형", "이미지경로", "설명문"} for v in visuals)
assert all(os.path.exists(v["이미지경로"]) for v in visuals), "그래프 파일이 없음"
data["시각자료설명"] = visuals
with open("mywork/press_data.json", "w", encoding="utf-8") as f:
    json.dump(data, f, ensure_ascii=False, indent=2)
print("그래프:", sorted({v["이미지경로"] for v in visuals}))
print("Ch06 OK — 시각자료설명 저장")
```

## 7. 관찰 — 주어, 변곡점, 조사

```python
# 관찰 Ch06
import sys, json
import pandas as pd
sys.path.insert(0, ".")

with open("mywork/press_data.json", encoding="utf-8") as f:
    data = json.load(f)
h = pd.DataFrame(data["월별이력"]).rename(columns={"값": "거래액"}).sort_values("연월").reset_index(drop=True)
h["증감"] = h["거래액"].diff()
h["방향바뀜"] = h["증감"] * h["증감"].shift(-1) < 0
print(h.tail(6).to_string(index=False))
for v in data["시각자료설명"]:
    print(f"[{v['소주제']}] {v['설명문']}")
```

[품목별 비중] 품목별 비중을 살펴보면 의류이 전체의 32.3%로 가장 큰 비중을 차지하였으며, 가전(25.8%), 식품(23.9%)이 그 뒤를 이었다.

**무엇을 설명할까**

- 2025-09는 감소(−1,600) 다음에 증가(+2,251)가 오는 **변곡점**입니다. 설명문은 마지막 변곡점을 언급합니다(슬라이드 10의 설명 포인트).
- 모든 설명문에 주어(품목명·"온라인쇼핑 거래액")가 있습니다. 주어가 없으면 이후 AI가 무엇에 대한 문장인지 추측해야 합니다.
- "의류**이**", "기타**은**"처럼 조사가 어색합니다. 템플릿의 조사가 고정되어 생기는 문제로, 강의대로 **LLM으로 표현만 다듬어** 해결합니다(8절, 그리고 8차시 본문 확장).

## 8. (선택) LLM으로 설명문 다듬기 (1회, 비용 발생)

`.env`에 키가 있을 때 실행합니다(슬라이드 16). 숫자·단위를 그대로 두라는 제약이 핵심입니다.

```python
# 선택 Ch06 — LLM으로 설명문 표현만 다듬기 (1회, 비용 발생)
import sys, json
sys.path.insert(0, ".")
from mywork.write import call_claude
from mywork.review import find_unverified_numbers

with open("mywork/press_data.json", encoding="utf-8") as f:
    data = json.load(f)
원문 = data["시각자료설명"][0]["설명문"]
prompt = f"""다음 규칙 기반 설명문을 보도자료 문체로 자연스럽게 다듬어 주세요.
원문의 숫자와 단위는 표기 그대로 모두 유지하십시오(예: 65,000억 원을 6조 5,000억 원으로 바꾸지 말 것).
새로운 숫자나 사실을 추가하지 말고 문장 표현만 개선하십시오. 다듬은 문장만 출력하십시오.

원문: {원문}"""
결과 = call_claude(prompt)
print("원문:", 원문)
print("다듬음:", 결과)
print("근거 없는 숫자:", find_unverified_numbers(결과, data))
```

"의류이 → 의류가"처럼 조사가 고쳐지고, `근거 없는 숫자`가 `[]`이면 됩니다. 이 결과는 저장하지 않습니다(8차시에서 설명문을 본문 단락으로 확장할 때 같은 방식으로 다듬어집니다).
