# 10분 단축 실습 — 전체 진행 안내 (2~10차시)

각 차시의 강의(`labs/강의자료/CHNN-ContentV10.pptx`)를 들은 뒤 **10분 안에** 진행하는 실습입니다. 수강생은 **Claude Code에게 프롬프트를 주어** 강의에서 배운 기능을 직접 만들게 하고, 짧은 검증 코드로 결과를 확인합니다.

- **차시별 문서 하나만 보고 진행**할 수 있습니다. 명령, 프롬프트, CLAUDE.md 내용, 검증 코드, 기대 결과, 실패 시 대처가 모두 문서 안에 있습니다.
- **2차시는 완전히 새로 시작**합니다(파이썬 확인 → 새 폴더 `C:\dev\quick-practice` → 가상환경 → `requirements.txt` → `CLAUDE.md`). 3~10차시는 같은 폴더에서 이어갑니다.
- **10분의 기준**: 설명하는 시간 + 명령·프롬프트를 입력하는 시간 + 결과 화면을 해설하는 시간. 패키지 설치, 코드 생성, API 응답을 기다리는 시간은 촬영 후 편집으로 잘라냅니다.
- 강의 코드는 원리를 보여 주는 핵심 코드이므로, **실습 코드의 기준은 각 문서의 프롬프트**입니다. 강의와 다른 점은 문서마다 "강의 내용과 실습의 연결" 표에 적어 두었습니다.

**모든 차시의 공통 흐름** (문서의 절 번호도 같습니다)

1. **시작 전 준비** — `Set-Location C:\dev\quick-practice` → `.\.venv\Scripts\Activate.ps1` → `$env:PYTHONUTF8 = "1"`
2. **입력 준비** — 필요한 원자료를 만들거나, 빠진 앞 차시 결과를 채웁니다. 앞 차시를 건너뛰었다면 "단독 시작" 명령을 실행합니다.
3. **CLAUDE.md에 차시 블록 추가** — 붙여넣기 한 번. 이미 있으면 건너뜁니다(중복 방지).
4. **Claude Code 새로 시작 → 프롬프트 붙여넣기** — CLAUDE.md는 세션 시작 때 읽히므로 반드시 새로 시작합니다.
5. **생성 결과 확인** — `python -c "import mywork.…"`
6. **검증** — `check.py`에 붙여넣고 `python check.py`. LLM 차시는 **가짜 응답**으로 구조만 확인하므로 비용이 들지 않습니다. 실패하면 오류 메시지를 Claude Code에 붙여 수정 요청 1회.
7. **관찰** — 강의 포인트를 눈으로 확인하는 짧은 실험
8. **실제 API 호출(권장·선택)** — `.env`에 키가 있을 때. 결과는 매번 표현이 다르며 숫자만 검증합니다.
9. **폴백** — 그래도 안 되면 정답 코드를 복사하고 6절 검증을 다시 실행
10. **문제 해결** 표, 11. **끝내기 체크리스트**
