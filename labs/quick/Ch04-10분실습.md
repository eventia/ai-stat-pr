## 1. 시작 전 체크리스트 (1분)

1. 프로젝트 루트(`main.py`, `modules/`가 있는 폴더)에서 PowerShell을 엽니다.
2. 가상환경을 켭니다.

```powershell
myvenv\Scripts\Activate.ps1
$env:PYTHONUTF8 = "1"
```

3. 이 차시에 필요한 패키지가 설치되어 있는지 확인합니다(`OK`가 나오면 됩니다).

```powershell
python -c "import anthropic, dotenv; print('OK')"
```

   오류가 나면 `pip install -r requirements.txt` 를 실행합니다.

4. **API 키**: 선택 단계에서만 필요. 필요한 경우 프로젝트 루트의 `.env` 파일에 `ANTHROPIC_API_KEY=발급받은키` 한 줄이 있어야 합니다.
5. **검증 스니펫 실행 방법**: 이 문서의 `검증`·`관찰`·`입력` 코드는 다음 방법으로 실행합니다.
   - 프로젝트 루트에 `check.py`라는 새 파일을 만들고, 코드를 붙여넣어 저장한 뒤 `python check.py` 를 실행합니다. (다른 코드를 실행할 때는 같은 파일을 덮어씁니다. 실습이 끝나면 `check.py`는 지워도 됩니다.)
6. Claude Code는 **프로젝트 루트에서** 시작합니다(터미널에서 `claude`, 또는 데스크톱 앱의 Code 탭에서 이 프로젝트 폴더를 엽니다). CLAUDE.md는 세션 시작 때 읽히므로 3절을 마친 뒤 **새 세션**으로 시작합니다.

## 2. 입력 준비

이 차시는 `mywork/press_data.json`에 **`문서정보`, `계산지표`, `핵심내용`, `원문`, `NLP분석결과`** 필드가 있어야 합니다. 앞 차시를 그대로 진행했다면 이미 있고, 앞 차시를 건너뛰었다면 아래 스니펫이 **비어 있는 필드만** 채웁니다(이미 있는 값은 건드리지 않음).

```python
# 입력 Ch04
import json, os

NEED = json.loads("""{
  "문서정보": {
    "제목": "2026년 1월 온라인쇼핑 동향",
    "공표일자": "2026-03-01",
    "자료출처": "공공데이터포털 Open API"
  },
  "계산지표": {
    "총거래액": 201250,
    "전월대비증감률": 1.5,
    "전년동월대비증감률": 8.7
  },
  "핵심내용": [
    "온라인쇼핑 거래액 역대 최대 달성"
  ],
  "원문": "2026년 1월 온라인쇼핑 거래액은 201,250억 원으로 전월 대비 1.5% 증가하였다. 전년동월대비로는 8.7% 증가한 수치이다. 이는 역대 1월 기준 최대치를 기록한 것이다. 모바일쇼핑 거래액 비중은 전체의 78%를 차지하며 꾸준한 증가세를 보이고 있다.",
  "NLP분석결과": {
    "핵심키워드": [
      "온라인쇼핑",
      "전월",
      "기록",
      "기준",
      "역대"
    ],
    "주요문장": [
      "2026년 1월 온라인쇼핑 거래액은 201,250억 원으로 전월 대비 1.5% 증가하였다."
    ]
  }
}""")

os.makedirs("mywork", exist_ok=True)
path = "mywork/press_data.json"
data = {}
if os.path.exists(path):
    with open(path, encoding="utf-8") as f:
        data = json.load(f)
added = [k for k in NEED if k not in data]
for k in added:
    data[k] = NEED[k]
with open(path, "w", encoding="utf-8") as f:
    json.dump(data, f, ensure_ascii=False, indent=2)
print("입력 준비 완료 — 새로 채운 필드:", added or "없음(앞 차시 결과를 그대로 사용)")
```

**기대 출력**: `입력 준비 완료 — 새로 채운 필드: ...` (앞 차시를 했다면 `없음(앞 차시 결과를 그대로 사용)`)

## 3. CLAUDE.md 수정·추가

### 3-1. 기존 규칙 3줄 수정

`CLAUDE.md`를 편집기로 열어, 아래 3개 규칙의 **맨 끝에 괄호 문구를 덧붙입니다**(나머지 2개 규칙은 그대로). 실습 코드는 `modules/`가 아니라 `mywork/`에 만들기 때문에, 규칙이 가리키는 위치를 실습용으로도 읽히게 하려는 것입니다.

**1번째 규칙**

```text

## 4. Claude Code 프롬프트

아래 전체를 복사해 Claude Code에 붙여넣고, 파일 쓰기 승인 요청이 뜨면 승인합니다. 생성 위치는 전부 `mywork/` 안입니다(기존 `modules/`는 건드리지 않습니다).

```text
두 파일을 만들어줘.

[mywork/write.py]
- 맨 위에서 dotenv의 load_dotenv()를 먼저 호출하고, 그 다음에 anthropic 클라이언트를 만든다: client = anthropic.Anthropic()
  ★ (순서가 반대면 .env의 API 키를 못 읽어 인증 오류가 난다)
- MODEL_NAME = "claude-sonnet-4-5"  # ★ 모델 ID는 이 상수 한 곳에만 둔다. 값은 실습 시점에 콘솔에서 유효한 ID를 확인해 바꿀 수 있다.
- parse_json_response(response_text) -> dict|list :
  응답에 설명이나 ```json 코드펜스가 섞여 있어도 JSON만 뽑아 json.loads 한다.
  ★ 문자열에서 처음 나오는 '{' 또는 '[' 중 먼저 나온 것을 시작점으로 잡고, 닫는 괄호는 "같은 종류의 닫는 괄호가 문자열 전체에서 마지막으로 나오는 위치"로 한다. 시작 괄호가 하나도 없으면 전체를 그대로 json.loads.
  (정규식 `\{.*\}|\[.*\]`처럼 객체를 먼저 찾으면 [{...},{...}] 배열 응답에서 안쪽 객체만 잘려 "Extra data" 파싱 오류가 난다)
- build_summary_prompt(data) -> str :
  data["계산지표"], data["NLP분석결과"]["핵심키워드"], data["NLP분석결과"]["주요문장"]의 첫 문장(없으면 빈 문자열)을 써서 "3줄 요약과 제목 후보 3개"를 요청하는 프롬프트 문자열을 만든다.
  계산지표는 "총거래액 {값}억 원, 전월대비 {값}% 증가, 전년동월대비 {값}% 증가" 형태로 넣고, 마지막에 반드시 이 JSON 형식으로만 출력하라고 지시한다: {"삼줄요약": ["문장1","문장2","문장3"], "제목후보": ["제목1","제목2","제목3"]}
- generate_summary(data) -> dict :
  build_summary_prompt로 프롬프트를 만들어 client.messages.create(model=MODEL_NAME, max_tokens=500, system="당신은 통계청 보도자료 작성 담당자입니다. 제공된 숫자만 사용하고 반드시 JSON 형식으로만 답하십시오.", messages=[{"role":"user","content":프롬프트}])를 호출하고 parse_json_response(message.content[0].text)를 반환.

[mywork/review.py]  — 이번 차시에는 아래 두 함수만 만든다. 나머지 검수 함수는 9차시에 이어서 추가할 것이므로 미리 만들지 말 것.
- find_unverified_numbers(text, data) -> list[str] :
  text에서 숫자(정규식 r'\d[\d,]*\.?\d*')를 모두 찾아, 원본 data로 근거를 확인할 수 없는 숫자만 원문 표기 그대로 반환한다.
  * 유효 숫자 집합 = data["계산지표"]의 숫자값(int/float) + data.get("품목별지표", [])의 각 행의 숫자값을 str로 모은 것.
  * ★ 각 값의 절댓값도 함께 등록한다(감소는 문장에서 "1.5% 감소"처럼 부호 없이 쓰므로, 음수 그대로만 등록하면 정상 문장이 전부 불일치로 오탐된다).
  * 비교 전 숫자의 콤마를 제거한다("201,250" → "201250").
  * 대조에서 제외(저위험): 소수점이 없고 2자리 이하인 숫자, 1900~2100 사이의 4자리 연도. 소수(증감률 등)는 항상 대조한다.
- verify_numbers(text, data) -> bool : find_unverified_numbers 결과가 비어 있으면 True.
```

**프롬프트에 꼭 들어간 것과, 빠지면 생기는 문제**

| 프롬프트에 꼭 들어간 것 | 빠지면 생기는 문제 |
| --- | --- |
| `load_dotenv()`를 클라이언트 생성보다 먼저 | 인증 오류로 첫 호출부터 실패 |
| 배열/객체 중 먼저 나온 괄호 기준 파싱 | 배열 응답이 "Extra data"로 파싱 실패 |
| 절댓값 함께 등록 | 하락 통계의 정상 문장이 전부 오탐 |
| 콤마 제거·연도·2자리 제외 | "201,250"이 불일치로 잡히거나 연도·순위가 오탐 |
| MODEL_NAME 상수 한 곳 | 모델 교체 시 여러 파일을 고쳐야 함(CLAUDE.md 원칙) |

## 7. 함정 관찰 (2분) — 감소 문장의 숫자 검증 (부호와 절댓값)

이 차시에서 프롬프트의 ★ 항목이 왜 필요한지 눈으로 확인합니다. `check.py`로 저장해 실행합니다.

```python
# 관찰 Ch04
import sys, json
sys.path.insert(0, ".")
from mywork.review import verify_numbers

with open("mywork/press_data.json", encoding="utf-8") as f:
    data = json.load(f)
data["계산지표"]["전월대비증감률"] = -1.5
print("감소 문장(1.5% 감소):", verify_numbers("전월 대비 1.5% 감소하였다.", data))
print("틀린 수치(2.5% 감소):", verify_numbers("전월 대비 2.5% 감소하였다.", data))
```

**예시 출력**(생성된 코드에 따라 표현은 조금 다를 수 있습니다)

```text
감소 문장(1.5% 감소): True
틀린 수치(2.5% 감소): False
```

**무엇을 볼 것인가**

- 원본이 -1.5인데 문장은 "1.5% 감소"라고 부호 없이 씁니다. 절댓값도 유효 숫자로 등록했기 때문에 정상 문장은 통과하고, 원본에 없는 2.5는 잡힙니다.
- 절댓값 등록이 없으면 하락 통계의 정상 문장이 전부 "불일치"로 오탐됩니다(프로젝트에서 실제로 겪은 버그).

## 9. 폴백 — 4:00까지 안 되면

생성이 끝나지 않거나 검증이 끝내 통과하지 않으면, 기존 파일을 복사해 다음으로 넘어갑니다(PowerShell, 프로젝트 루트).

```powershell
New-Item mywork\__init__.py -ItemType File -Force
Copy-Item modules\config.py mywork\config.py
Copy-Item modules\write.py mywork\write.py
Copy-Item modules\review.py mywork\review.py

# 복사한 파일이 mywork의 다른 모듈을 불러오도록 import 경로를 바꿉니다 (modules. -> mywork.)
Get-ChildItem mywork\*.py | ForEach-Object {
    (Get-Content $_.FullName -Raw -Encoding UTF8) -replace 'from modules\.io','from mywork.data_io' -replace 'from modules\.(?!export)','from mywork.' | Set-Content $_.FullName -Encoding UTF8
}
```

기존 파일에는 이후 차시의 함수까지 다 들어 있어 그대로 써도 됩니다. `write.py`가 `mywork/config.py`를 import 하므로 config도 함께 복사합니다.

위 명령의 마지막 부분이 복사한 파일의 import 경로를 `modules.`에서 `mywork.`로 바꿉니다(그래야 복사한 파일이 여러분이 만든 `mywork/write.py` 등을 함께 씁니다. `main.py`의 `modules.export`만 그대로 남습니다). 모든 명령은 **프로젝트 루트에서 실행**하고, 복사 후에는 6절 검증만 다시 실행합니다.

## 10. 문제 해결

| 증상 | 원인 | 조치 |
| --- | --- | --- |
| `AuthenticationError`(선택 단계) | .env 키 오류 또는 `load_dotenv()` 순서 | `.env`의 `ANTHROPIC_API_KEY` 확인, `write.py`에서 `load_dotenv()`가 `Anthropic()`보다 먼저인지 확인 |
| 키 없이도 검증이 되나요? | `Anthropic()` 객체는 키 없이도 만들어짐(호출할 때만 키 필요) | 기본 검증은 API를 부르지 않으므로 키 없이 진행 가능 |
| `ModuleNotFoundError: No module named 'mywork'` | 프로젝트 루트가 아닌 곳에서 실행했거나 `mywork/__init__.py`가 없음 | 프로젝트 루트로 이동(`cd`) 후 다시 실행. `New-Item mywork\__init__.py -ItemType File -Force` |
| 한글이 `???`·깨진 글자로 출력 | PowerShell 기본 코드페이지(cp949) | `$env:PYTHONUTF8 = "1"` 후 다시 실행 |
| `ModuleNotFoundError: No module named 'pandas'` 등 패키지 없음 | 가상환경 미활성화 또는 미설치 | `myvenv\Scripts\Activate.ps1` 후 `pip install -r requirements.txt` |
| Claude Code가 `modules/`를 열어 보거나 복사해서 만듦 | CLAUDE.md 규칙이 적용되지 않음 | 3절을 다시 확인하고 **새 세션**으로 시작. 이미 만들어졌다면 그 파일을 지우고 프롬프트를 다시 붙여넣기 |
| `AssertionError`가 나옴 | 생성 코드가 프롬프트의 ★ 항목 중 일부를 빠뜨림 | 오류 메시지와 `check.py` 결과를 Claude Code에 **그대로 붙여** 수정 요청(1회). 그래도 안 되면 폴백 |
| 생성이 4분 넘게 끝나지 않음 | 생성 지연 또는 프롬프트 오해 | 중단하고 폴백(9절)으로 진행. 검증 스니펫은 그대로 실행 |
