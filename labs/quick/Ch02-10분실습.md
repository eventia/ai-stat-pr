# Ch 02 10분 실습 — 정제·표준화·구조화

> **이 문서 하나만 보고 진행할 수 있습니다.** 실행할 명령, 붙여넣을 프롬프트, 검증 코드, CLAUDE.md 수정 내용, 기대 결과, 실패했을 때의 대처까지 모두 이 안에 있습니다.
> 원리는 이렇습니다: 미리 만들어진 코드를 실행하는 대신, **Claude Code에게 프롬프트를 주어 같은 기능의 코드를 직접 만들게** 하고, 짧은 검증 코드로 결과를 확인합니다.

## 0. 한눈에 보기

| 항목 | 내용 |
| --- | --- |
| 만드는 파일 | `mywork/__init__.py`(빈 파일), `mywork/config.py`, `mywork/clean.py` |
| 입력 | 없음 (첫 차시) |
| 결과 | `mywork/press_data.json` 신규 생성 — `문서정보`·`계산지표`·`핵심내용`·`원문` |
| LLM 호출(비용) | 0회 (API 키: 필요 없음) |
| 소요 시간 | 10분 |

**10분 진행표**

| 시각 | 할 일 |
| --- | --- |
| 0:00 | 입력 확인 |
| 1:00 | 프롬프트→생성 |
| 4:00 | 검증 스니펫 |

## 1. 시작 전 체크리스트 (1분)

1. 프로젝트 루트(`main.py`, `modules/`가 있는 폴더)에서 PowerShell을 엽니다.
2. 가상환경을 켭니다.

```powershell
myvenv\Scripts\Activate.ps1
$env:PYTHONUTF8 = "1"
```

3. 이 차시에 필요한 패키지가 설치되어 있는지 확인합니다(`OK`가 나오면 됩니다).

```powershell
python -c "import re, json; print('OK')"
```

   오류가 나면 `pip install -r requirements.txt` 를 실행합니다.

4. **API 키**: 필요 없음.
5. **검증 스니펫 실행 방법**: 이 문서의 `검증`·`관찰`·`입력` 코드는 다음 방법으로 실행합니다.
   - 프로젝트 루트에 `check.py`라는 새 파일을 만들고, 코드를 붙여넣어 저장한 뒤 `python check.py` 를 실행합니다. (다른 코드를 실행할 때는 같은 파일을 덮어씁니다. 실습이 끝나면 `check.py`는 지워도 됩니다.)
6. Claude Code는 **프로젝트 루트에서** 시작합니다(터미널에서 `claude`, 또는 데스크톱 앱의 Code 탭에서 이 프로젝트 폴더를 엽니다). CLAUDE.md는 세션 시작 때 읽히므로 3절을 마친 뒤 **새 세션**으로 시작합니다.

## 2. 입력 준비

2차시는 첫 차시라 준비할 입력이 없습니다. `mywork/press_data.json`은 이 차시의 검증 스니펫이 만듭니다.

## 3. CLAUDE.md 수정·추가

`CLAUDE.md`(프로젝트 루트)는 Claude Code가 세션을 시작할 때 자동으로 읽는 **프로젝트 규칙 파일**입니다. 프롬프트에 매번 쓰지 않아도 되는 공통 규칙과, 이번 차시에서 얻은 교훈(함정)을 여기에 규칙으로 남깁니다. 프롬프트는 "이번 차시에 무엇을 만들지", CLAUDE.md는 "프로젝트 내내 지킬 규칙"을 맡습니다.

### 3-0. 백업 (2차시에서 한 번만)

실습이 끝나면 원래대로 되돌릴 수 있도록 먼저 복사해 둡니다.

```powershell
Copy-Item CLAUDE.md CLAUDE.md.bak
```

### 3-1. 기존 규칙 3줄 수정

`CLAUDE.md`를 편집기로 열어, 아래 3개 규칙의 **맨 끝에 괄호 문구를 덧붙입니다**(나머지 2개 규칙은 그대로). 실습 코드는 `modules/`가 아니라 `mywork/`에 만들기 때문에, 규칙이 가리키는 위치를 실습용으로도 읽히게 하려는 것입니다.

**1번째 규칙**

```text
수정 전: - 수치 계산(증감률, 비중, 순위 등)은 반드시 `modules/stats.py`의 파이썬 함수가 처리하며, AI 모델에게 계산을 맡기지 않는다.
수정 후: - 수치 계산(증감률, 비중, 순위 등)은 반드시 `modules/stats.py`의 파이썬 함수가 처리하며, AI 모델에게 계산을 맡기지 않는다. (10분 실습에서는 `mywork/stats.py`)
```

**2번째 규칙**

```text
수정 전: - AI가 생성한 문장은 `modules/review.py`의 `verify_numbers`/`cross_check_all_numbers`로 원본 수치와 반드시 교차 검증한다.
수정 후: - AI가 생성한 문장은 `modules/review.py`의 `verify_numbers`/`cross_check_all_numbers`로 원본 수치와 반드시 교차 검증한다. (10분 실습에서는 `mywork/review.py`)
```

**3번째 규칙**

```text
수정 전: - 모델 ID는 `modules/write.py`의 `MODEL_NAME` 상수 한 곳에서만 관리한다.
수정 후: - 모델 ID는 `modules/write.py`의 `MODEL_NAME` 상수 한 곳에서만 관리한다. (10분 실습에서는 `mywork/write.py`)
```

`CLAUDE.md` **맨 아래**에 빈 줄 하나를 띄우고 아래 블록을 그대로 붙여넣습니다(HTML 주석은 나중에 이 부분만 찾아 지우기 위한 표시이므로 지우지 마세요).

```markdown

```

## 4. Claude Code 프롬프트

아래 전체를 복사해 Claude Code에 붙여넣고, 파일 쓰기 승인 요청이 뜨면 승인합니다. 생성 위치는 전부 `mywork/` 안입니다(기존 `modules/`는 건드리지 않습니다).

```text
mywork/ 폴더에 다음 3개 파일을 만들어줘. (mywork/__init__.py 는 빈 파일)

[mywork/config.py]  — 데이터 딕셔너리(항목 정의)를 상수로 둔다.
- PRIMARY_INDICATOR = "총거래액", PRIMARY_UNIT = "억 원"
- REQUIRED_FIELDS = ["총거래액", "전월대비증감률", "전년동월대비증감률"]   # 제목·리드문에 반드시 들어가는 필수 항목
- INDICATOR_UNITS = {"총거래액": "억 원", "전월대비증감률": "%", "전년동월대비증감률": "%"}

[mywork/clean.py]
mask_sensitive_info(text: str) -> str
- 주민등록번호(예: 900101-1234567)는 "******-*******"로, 휴대전화(010/011/016/017/018/019로 시작, 앞 3자리 - 가운데 3~4자리 - 뒤 4자리, 예: 010-1234-5678, 011-123-4567)는 "010-****-****"로 치환한다. 정규표현식 사용.

clean_and_structure(raw: dict) -> dict
- 입력 raw 키: 제목, 공표일자, 자료출처(없을 수 있음), 계산지표(dict), 핵심내용(list), 원문(str)
- 원문 정제: (1) 연속 공백·줄바꿈을 공백 하나로 (2) 앞뒤 공백 제거 (3) "(주:...)" 형태의 괄호 주석 제거
- 원문 표준화: 숫자 바로 뒤의 "억원"→"억 원", "백만원"→"백만 원". 그다음 mask_sensitive_info를 적용한다.
- 반환 구조(키 이름은 한글 그대로):
  {"문서정보": {"제목", "공표일자", "자료출처"(없으면 "공공데이터포털 Open API")},
   "계산지표": raw["계산지표"] 그대로, "핵심내용": raw["핵심내용"] 그대로, "원문": 정제된 문장}
- ★ 계산지표는 다시 계산하거나 바꾸지 말고 그대로 옮긴다. 이 함수는 구조만 표준화하고 계산은 하지 않는다(계산은 5차시 stats가 담당).
- raw에 "품목별지표", "역대최대여부", "최근3개월증감률", "월별이력"이 있으면 계산 없이 그대로 결과에 함께 전달한다.
```

**프롬프트에 꼭 들어간 것과, 빠지면 생기는 문제**

| 프롬프트에 꼭 들어간 것 | 빠지면 생기는 문제 |
| --- | --- |
| 계산지표를 그대로 통과(계산 금지) | 정제 단계에서 값이 바뀌면 이후 모든 수치 검증의 기준이 흔들림(CLAUDE.md 원칙 1) |
| 단위 표준화 "억원→억 원" | 9차시 `check_formatting_errors`의 단위 표기 검사에 걸림 |
| 마스킹을 정제 안에서 항상 적용 | 통계 원문에 섞인 담당자 연락처가 LLM으로 전송됨(1차시 보안 원칙) |
| 표준 구조 키 이름을 한글 그대로 | 3~10차시 모든 코드가 이 키(`문서정보`, `계산지표`…)를 그대로 읽음 |

## 6. 검증 (핵심)

아래를 `check.py`로 저장해 실행합니다.

```python
    "제목": "2026년 1월 온라인쇼핑 동향", "공표일자": "2026-03-01",
    "계산지표": {"총거래액": 201250, "전월대비증감률": 1.5, "전년동월대비증감률": 8.7},

assert r["문서정보"]["자료출처"] == "공공데이터포털 Open API"
assert mask_sensitive_info("900101-1234567") == "******-*******"

    "제목": "2026년 1월 온라인쇼핑 동향", "공표일자": "2026-03-01", "자료출처": "공공데이터포털 Open API",
    "계산지표": {"총거래액": 201250, "전월대비증감률": 1.5, "전년동월대비증감률": 8.7},
    "핵심내용": ["온라인쇼핑 거래액 역대 최대 달성"],
    "원문": ("2026년 1월 온라인쇼핑 거래액은 201,250억 원으로 전월 대비 1.5% 증가하였다. "
             "전년동월대비로는 8.7% 증가한 수치이다. 이는 역대 1월 기준 최대치를 기록한 것이다. "
             "모바일쇼핑 거래액 비중은 전체의 78%를 차지하며 꾸준한 증가세를 보이고 있다."),
}
os.makedirs("mywork", exist_ok=True)
with open("mywork/press_data.json", "w", encoding="utf-8") as f:
    json.dump(clean_and_structure(base), f, ensure_ascii=False, indent=2)
print("Ch02 OK — mywork/press_data.json 저장")
```

## 7. 함정 관찰 (2분) — 마스킹·단위 표준화 눈으로 확인

이 차시에서 프롬프트의 ★ 항목이 왜 필요한지 눈으로 확인합니다. `check.py`로 저장해 실행합니다.

```python
# 관찰 Ch02
import sys
sys.path.insert(0, ".")
from mywork.clean import mask_sensitive_info, clean_and_structure

for s in ["문의 010-1234-5678", "문의 011-123-4567", "주민 900101-1234567", "문의 02-123-4567"]:
    print(s, "->", mask_sensitive_info(s))

r = clean_and_structure({"제목": "t", "공표일자": "2026-03-01", "계산지표": {"총거래액": 201250},
                         "핵심내용": [], "원문": "거래액은 201,250억원이다."})
print(r["원문"], "|", r["계산지표"])
```

**예시 출력**(생성된 코드에 따라 표현은 조금 다를 수 있습니다)

```text
문의 010-1234-5678 -> 문의 010-****-****
문의 011-123-4567 -> 문의 010-****-****
주민 900101-1234567 -> 주민 ******-*******
문의 02-123-4567 -> 문의 02-123-4567
거래액은 201,250억 원이다. | {'총거래액': 201250}
```

**무엇을 볼 것인가**

- 011로 시작하는 번호도 `010-****-****`로 바뀝니다(앞자리도 가려짐). 지역번호(02)는 휴대전화가 아니라서 그대로입니다.
- `억원` → `억 원`으로 띄어쓰기가 통일되었고, `계산지표`는 값이 그대로입니다(정제 단계는 계산하지 않습니다).

## 9. 폴백 — 4:00까지 안 되면

생성이 끝나지 않거나 검증이 끝내 통과하지 않으면, 기존 파일을 복사해 다음으로 넘어갑니다(PowerShell, 프로젝트 루트).

```powershell
New-Item mywork\__init__.py -ItemType File -Force
Copy-Item modules\config.py mywork\config.py
Copy-Item modules\clean.py mywork\clean.py

# 복사한 파일이 mywork의 다른 모듈을 불러오도록 import 경로를 바꿉니다 (modules. -> mywork.)
Get-ChildItem mywork\*.py | ForEach-Object {
    (Get-Content $_.FullName -Raw -Encoding UTF8) -replace 'from modules\.io','from mywork.data_io' -replace 'from modules\.(?!export)','from mywork.' | Set-Content $_.FullName -Encoding UTF8
}
```

복사한 기존 파일도 그대로 검증을 통과해야 합니다.

위 명령의 마지막 부분이 복사한 파일의 import 경로를 `modules.`에서 `mywork.`로 바꿉니다(그래야 복사한 파일이 여러분이 만든 `mywork/write.py` 등을 함께 씁니다. `main.py`의 `modules.export`만 그대로 남습니다). 모든 명령은 **프로젝트 루트에서 실행**하고, 복사 후에는 6절 검증만 다시 실행합니다.

## 10. 문제 해결

| 증상 | 원인 | 조치 |
| --- | --- | --- |
| `010-****-****`가 안 나옴 | 전화번호 정규식 오류 | 프롬프트의 휴대전화 조건(앞 3자리-가운데 3~4자리-뒤 4자리)을 다시 확인해 수정 요청 |
| `ModuleNotFoundError: No module named 'mywork'` | 프로젝트 루트가 아닌 곳에서 실행했거나 `mywork/__init__.py`가 없음 | 프로젝트 루트로 이동(`cd`) 후 다시 실행. `New-Item mywork\__init__.py -ItemType File -Force` |
| 한글이 `???`·깨진 글자로 출력 | PowerShell 기본 코드페이지(cp949) | `$env:PYTHONUTF8 = "1"` 후 다시 실행 |
| `ModuleNotFoundError: No module named 'pandas'` 등 패키지 없음 | 가상환경 미활성화 또는 미설치 | `myvenv\Scripts\Activate.ps1` 후 `pip install -r requirements.txt` |
| Claude Code가 `modules/`를 열어 보거나 복사해서 만듦 | CLAUDE.md 규칙이 적용되지 않음 | 3절을 다시 확인하고 **새 세션**으로 시작. 이미 만들어졌다면 그 파일을 지우고 프롬프트를 다시 붙여넣기 |
| `AssertionError`가 나옴 | 생성 코드가 프롬프트의 ★ 항목 중 일부를 빠뜨림 | 오류 메시지와 `check.py` 결과를 Claude Code에 **그대로 붙여** 수정 요청(1회). 그래도 안 되면 폴백 |
| 생성이 4분 넘게 끝나지 않음 | 생성 지연 또는 프롬프트 오해 | 중단하고 폴백(9절)으로 진행. 검증 스니펫은 그대로 실행 |
