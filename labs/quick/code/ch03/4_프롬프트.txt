mywork/nlp.py 를 만들어줘. 생성형 AI는 쓰지 않고 형태소 분석·TF-IDF·TextRank만 쓴다.
(kiwipiepy, scikit-learn, networkx 사용)

- 모듈 전역에서 Kiwi()를 한 번만 만들고, "온라인쇼핑", "모바일쇼핑", "거래액", "역대급"을
  add_user_word(단어, "NNP", 0.0)로 사용자 사전에 등록한다.
- STOPWORDS = {"등", "및", "수", "것"}

extract_nouns(text: str) -> list
- Kiwi tokenize 결과 중 품사 태그가 "NN"으로 시작하는 토큰의 form만 순서대로 돌려준다.

split_sentences(text: str) -> list
- 마침표·느낌표·물음표 뒤의 공백을 기준으로 나눈다(re.split(r"(?<=[.!?])\s+", ...)). 앞뒤 공백 제거, 빈 문장 제외.

clean_keywords(keyword_scores, top_n: int = 5) -> list
- 불용어와 한 글자 단어를 빼고, 점수 내림차순으로 상위 top_n개의 (단어, 점수)를 돌려준다.

extract_keywords_tfidf(text: str, top_n: int = 5) -> list
- ★ 문서가 1건이므로 문장 하나하나를 문서로 취급한다: 문장별 명사를 공백으로 이어 붙인 문자열 목록(빈 것 제외)에 TfidfVectorizer를 적용한다.
- 단어마다 여러 문장 중 최고 점수를 대표 점수로 쓴다. 단어는 str, 점수는 파이썬 float(소수점 4자리 반올림)로 만든다.
- 마지막에 clean_keywords(..., top_n)로 정리해 돌려준다.

extract_main_sentences(sentences: list, ratio: float = 0.5) -> list   (TextRank)
- 문장이 1개 이하면 그대로 돌려준다.
- 문장별 명사 문자열(명사가 없으면 원 문장)을 TF-IDF로 벡터화하고 cosine_similarity로 유사도 행렬을 만든다.
- ★ 대각선(자기 자신과의 유사도)을 0으로 만든 뒤 networkx.from_numpy_array → pagerank로 점수를 구한다.
- 점수 상위 max(1, round(문장수 * ratio))개를 고르되, ★ 원문 순서대로 돌려준다(문장은 고치지 않고 그대로).

filter_sentences_by_keywords(sentences: list, keywords: list) -> list
- 키워드를 하나라도 포함한 문장만 원래 순서대로 돌려준다.

analyze_document(raw_text: str, standard_data: dict) -> dict
- 키워드(단어만) = extract_keywords_tfidf(raw_text)
- 주요문장 = extract_main_sentences(split_sentences(raw_text))를 filter_sentences_by_keywords로 다시 거른 것
- standard_data["NLP분석결과"] = {"핵심키워드": [...], "주요문장": [...]} 로 넣고 standard_data를 돌려준다.
