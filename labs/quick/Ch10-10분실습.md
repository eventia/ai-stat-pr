> **이 문서 하나만 보고 진행할 수 있습니다.** 실행할 명령, 붙여넣을 프롬프트, 검증 코드, CLAUDE.md 수정 내용, 기대 결과, 실패했을 때의 대처까지 모두 이 안에 있습니다.

## 1. 시작 전 체크리스트 (1분)

1. 프로젝트 루트(`main.py`, `modules/`가 있는 폴더)에서 PowerShell을 엽니다.
2. 가상환경을 켭니다.

```powershell
myvenv\Scripts\Activate.ps1
$env:PYTHONUTF8 = "1"
```

3. 이 차시에 필요한 패키지가 설치되어 있는지 확인합니다(`OK`가 나오면 됩니다).

```powershell
python -c "import pandas, matplotlib, anthropic, dotenv, reportlab, hwpx; print('OK')"
```

   오류가 나면 `pip install -r requirements.txt` 를 실행합니다.

4. **API 키**: 실제 실행에만 필요. 필요한 경우 프로젝트 루트의 `.env` 파일에 `ANTHROPIC_API_KEY=발급받은키` 한 줄이 있어야 합니다.
5. **검증 스니펫 실행 방법**: 이 문서의 `검증`·`관찰`·`입력` 코드는 다음 방법으로 실행합니다.
   - 프로젝트 루트에 `check.py`라는 새 파일을 만들고, 코드를 붙여넣어 저장한 뒤 `python check.py` 를 실행합니다. (다른 코드를 실행할 때는 같은 파일을 덮어씁니다. 실습이 끝나면 `check.py`는 지워도 됩니다.)
6. Claude Code는 **프로젝트 루트에서** 시작합니다(터미널에서 `claude`, 또는 데스크톱 앱의 Code 탭에서 이 프로젝트 폴더를 엽니다). CLAUDE.md는 세션 시작 때 읽히므로 3절을 마친 뒤 **새 세션**으로 시작합니다.

## 4. Claude Code 프롬프트

아래 전체를 복사해 Claude Code에 붙여넣고, 파일 쓰기 승인 요청이 뜨면 승인합니다. 생성 위치는 전부 `mywork/` 안입니다(기존 `modules/`는 건드리지 않습니다).

> 이 차시는 PDF·HWPX 저장 코드를 **새로 만들지 않고** 기존 `modules/export.py`의 함수를 그대로 불러 씁니다(PDF·HWPX 변환은 학습 초점이 아니기 때문). CLAUDE.md 공통 규칙의 "modules/를 열지 않는다"에서 이 파일만 예외입니다(3-3 블록에 적혀 있음).

```text
mywork/main.py 를 만들어줘. 지금까지 만든 mywork 모듈들을 하나의 파이프라인으로 연결한다.

- ★ 맨 위에서 load_dotenv()를 먼저 호출한 뒤에 mywork.write / mywork.review 를 import 한다. (그 모듈들이 import 시점에 Anthropic 클라이언트를 만들기 때문에 순서가 반대면 API 키를 못 읽는다)
- ★ logs/ 폴더를 만들고(exist_ok) logging.basicConfig(filename="logs/pipeline_quick.log", level=logging.INFO, encoding="utf-8") 로 설정한다. (Windows에서 encoding을 빼면 한글 로그가 깨진다)
- main(파일경로) -> dict : 전체를 try/except로 감싸 "파이프라인 시작: 경로", "파이프라인 완료"는 logging.info로, 예외는 logging.error 후 다시 raise 한다. 실행 순서:
  1. raw = load_input(파일경로)                          (mywork.data_io)
  2. data = clean_and_structure(raw)                     (mywork.clean)
  3. data = analyze_document(data["원문"], data)         (mywork.nlp)
  4. data = add_calculated_indicators(data)              (mywork.stats)
  5. ★ "품목별지표" in data 또는 "월별이력" in data 이면 data["시각자료설명"] = build_visual_descriptions(data)  (mywork.charts; 품목별 데이터가 없어도 월별 이력만 있으면 꺾은선 그래프가 나오도록 or 조건)
  6. data["요약결과"] = generate_summary(data)           (참고용 — 제목 아이디어로만 쓰이며 사실 확정에는 쓰이지 않는다)
  7. data["헤드라인"] = generate_headline_set(data)
  8. data["본문"] = generate_body_paragraphs(data)
  9. data["최종본"] = unify_style(assemble_full_text(data))
  10. data["검수결과"] = {"표기오류검사": check_formatting_errors(최종본), "수치교차검증": cross_check_all_numbers(최종본, data), "AI감수지적사항": review_press_release(최종본, data)}
  11. save_final_document(data)로 txt 저장 → ★ PDF·HWPX는 이 실습에서 새로 만들지 않고, 기존 modules/export.py의 save_hwpx(data), save_pdf(data)를 그대로 import 해서 쓴다(CLAUDE.md의 "modules/를 열지 않는다" 규칙의 예외: `from modules.export import save_hwpx, save_pdf`). 형식마다 따로 try/except 로 호출해 data["출력파일"] = {"hwpx": 경로, "pdf": 경로}에 담는다. 실패하면(예: 한글 폰트가 없어 PDF 실패) logging.error와 print("[경고] ... 저장 실패")만 하고 계속 진행한다(이미 만든 결과와 다른 형식을 잃지 않기 위해). → data 반환
- if __name__ == "__main__": main("data/raw/온라인쇼핑동향_2026_01_상세.xlsx")를 실행하고 최종본, "수치 교차 검증 통과 여부", "표기 오류 검사" 결과, 저장된 파일 경로(data["출력파일"])를 출력한다.
- 실행은 프로젝트 루트에서 `python -m mywork.main`.
```

**프롬프트에 꼭 들어간 것과, 빠지면 생기는 문제**

| 프롬프트에 꼭 들어간 것 | 빠지면 생기는 문제 |
| --- | --- |
| `load_dotenv()` 먼저 | 첫 API 호출에서 인증 오류 |
| 로그 `encoding="utf-8"` | Windows에서 로그 한글이 깨져 원인 추적 불가 |
| 그래프 조건 `or` | 월별 이력만 있는 데이터에서 꺾은선 그래프가 안 나옴 |
| `generate_summary`를 참고용으로 호출 | 4차시 산출물이 최종본과 단절된 죽은 코드가 됨 |
| 검수 3종 모두 `검수결과`에 | AI 감수 하나만 믿게 되어 안전장치가 약해짐 |
| PDF·HWPX를 형식마다 따로 `try/except` | 폰트 없음 등으로 PDF가 실패하면 HWPX와 유료 API로 만든 결과까지 잃음 |
| 기본 입력을 `_상세.xlsx`로 | 기본 xlsx에는 품목별지표가 없어 본문이 0단락이 됨 |

### 6-1. 오프라인 검증 — API 키·비용 없이 배선과 출력 파일 확인

# 검증 Ch10-offline
import os, sys, json
sys.path.insert(0, ".")
os.environ.setdefault("ANTHROPIC_API_KEY", "dummy")
import mywork.write as w

class _Block:
    def __init__(self, text):
        self.text = text
class _Msg:
    def __init__(self, text):
        self.content = [_Block(text)]

def fake_create(*, model, max_tokens, messages, system=None, **kwargs):
    p = messages[0]["content"]
    if "삼줄요약" in p:
        return _Msg(json.dumps({"삼줄요약": ["a", "b", "c"], "제목후보": ["x", "y", "z"]}, ensure_ascii=False))
    if "제목" in p and "부제" in p and "리드문" in p:
        return _Msg(json.dumps({"제목": "1월 온라인쇼핑 거래액, 역대 최대", "부제": "모바일쇼핑 비중 78%로 지속 확대",
                                "리드문": "통계청은 2026년 1월 온라인쇼핑 거래액이 201,250억 원으로 집계되었다고 밝혔다."},
                               ensure_ascii=False))
    if "본문 한 단락" in p:

## 9. 폴백 — 4:00까지 안 되면

생성이 끝나지 않거나 검증이 끝내 통과하지 않으면, 기존 파일을 복사해 다음으로 넘어갑니다(PowerShell, 프로젝트 루트).

```powershell
New-Item mywork\__init__.py -ItemType File -Force
Copy-Item modules\config.py mywork\config.py
Copy-Item modules\clean.py mywork\clean.py
Copy-Item modules\nlp.py mywork\nlp.py
Copy-Item modules\stats.py mywork\stats.py
Copy-Item modules\charts.py mywork\charts.py
Copy-Item modules\write.py mywork\write.py
Copy-Item modules\review.py mywork\review.py
Copy-Item modules\io.py mywork\data_io.py
Copy-Item main.py mywork\main.py

# 복사한 파일이 mywork의 다른 모듈을 불러오도록 import 경로를 바꿉니다 (modules. -> mywork.)
Get-ChildItem mywork\*.py | ForEach-Object {
    (Get-Content $_.FullName -Raw -Encoding UTF8) -replace 'from modules\.io','from mywork.data_io' -replace 'from modules\.(?!export)','from mywork.' | Set-Content $_.FullName -Encoding UTF8
}
```

복사한 `main.py`는 로그를 `logs/pipeline.log`에, 기본 입력을 기본 xlsx(품목별지표 없음)로 씁니다. `_상세.xlsx`로 실행하려면 `python -c "import mywork.main as m; print(m.main('data/raw/온라인쇼핑동향_2026_01_상세.xlsx')['출력파일'])"` 를 실행하세요. PDF·HWPX 저장은 `modules/export.py`를 그대로 씁니다.

위 명령의 마지막 부분이 복사한 파일의 import 경로를 `modules.`에서 `mywork.`로 바꿉니다(그래야 복사한 파일이 여러분이 만든 `mywork/write.py` 등을 함께 씁니다. `main.py`의 `modules.export`만 그대로 남습니다). 모든 명령은 **프로젝트 루트에서 실행**하고, 복사 후에는 6절 검증만 다시 실행합니다.

## 10. 문제 해결

| 증상 | 원인 | 조치 |
| --- | --- | --- |
| `[경고] pdf 저장 실패` | 한글 TTF 폰트를 못 찾음 | `.env`에 `KOREAN_FONT_PATH=<한글 .ttf 경로>` 추가 (txt·HWPX는 정상 저장됨) |
| `AuthenticationError` | API 키 문제 | `.env`의 `ANTHROPIC_API_KEY` 확인, `main.py`에서 `load_dotenv()`가 import보다 먼저인지 확인 |
| HWPX가 한글에서 안 열림 | 자동 테스트는 구조 검증까지만 함 | 파일과 생성 코드를 공유해 주세요. 우선 PDF·txt는 정상인지 확인 |
| `ModuleNotFoundError: No module named 'mywork'` | 프로젝트 루트가 아닌 곳에서 실행했거나 `mywork/__init__.py`가 없음 | 프로젝트 루트로 이동(`cd`) 후 다시 실행. `New-Item mywork\__init__.py -ItemType File -Force` |
| 한글이 `???`·깨진 글자로 출력 | PowerShell 기본 코드페이지(cp949) | `$env:PYTHONUTF8 = "1"` 후 다시 실행 |
| `ModuleNotFoundError: No module named 'pandas'` 등 패키지 없음 | 가상환경 미활성화 또는 미설치 | `myvenv\Scripts\Activate.ps1` 후 `pip install -r requirements.txt` |
| Claude Code가 `modules/`를 열어 보거나 복사해서 만듦 | CLAUDE.md 규칙이 적용되지 않음 | 3절을 다시 확인하고 **새 세션**으로 시작. 이미 만들어졌다면 그 파일을 지우고 프롬프트를 다시 붙여넣기 |
| `AssertionError`가 나옴 | 생성 코드가 프롬프트의 ★ 항목 중 일부를 빠뜨림 | 오류 메시지와 `check.py` 결과를 Claude Code에 **그대로 붙여** 수정 요청(1회). 그래도 안 되면 폴백 |
| 생성이 4분 넘게 끝나지 않음 | 생성 지연 또는 프롬프트 오해 | 중단하고 폴백(9절)으로 진행. 검증 스니펫은 그대로 실행 |

### 실습 후 정리 (CLAUDE.md 원복)

실습용으로 수정한 CLAUDE.md는 프로젝트 전체 규칙이므로, 실습이 끝나면 되돌립니다. 두 가지 방법 중 하나를 씁니다.

**방법 A — 백업으로 통째로 되돌리기** (실습 중 CLAUDE.md의 다른 부분을 고치지 않았다면)

```powershell
Copy-Item CLAUDE.md.bak CLAUDE.md -Force
Remove-Item CLAUDE.md.bak
```

**방법 B — 실습 블록만 지우기** (규칙을 더 남기고 싶다면)

1. 3-1에서 덧붙인 3곳의 `(10분 실습에서는 ...)` 문구를 지웁니다.
2. `CLAUDE.md` 안의 `<!-- quick-practice:...:start -->` 부터 `<!-- quick-practice:...:end -->` 까지(공통 블록과 `ch02`~`ch10` 블록 전부)를 삭제합니다.
3. 확인: `Select-String -Path CLAUDE.md -Pattern "quick-practice","10분 실습에서는"` 결과가 비어 있어야 합니다.

정리 후 `mywork/`, `check.py`, `CLAUDE.md.bak`는 실습 산출물이므로 저장소에 커밋하지 않습니다(필요하면 삭제).
