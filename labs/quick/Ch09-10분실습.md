## 4. Claude Code 프롬프트

Claude Code를 **새로 시작**(`claude`)하고 아래를 붙여넣습니다.

```text
기존 함수는 고치지 말고 다음 함수를 추가해줘.

[mywork/write.py]
assemble_full_text(data: dict) -> str
- data["헤드라인"]["리드문"] + "\n\n" + assemble_body(data["본문"])
unify_style(draft_text: str) -> str
- 프롬프트: "아래 초안을 {ISSUER} 보도자료 문체로 통일해 주세요."
  조건: 모든 문장을 객관적 서술체(~하였다, ~로 나타났다)로 통일, 주관적 수식어(매우, 놀랍게도 등) 제거,
  ★ 사실과 수치는 절대 변경 금지(숫자·콤마·단위 표기 그대로), 단락 구분(빈 줄)은 그대로 유지,
  ★ "설명이나 머리말 없이 수정된 본문만 출력". 마지막에 "초안:" 다음 줄부터 draft_text를 넣는다.
- call_claude(prompt, max_tokens=3000) 결과를 돌려준다.

[mywork/review.py] — 맨 위에 import json 과 from mywork.write import call_claude, parse_json_response 를 추가한다.
check_formatting_errors(text: str) -> list  (정규식 기반 1차 필터, 오류 설명 문자열 목록)
- 숫자 바로 뒤 "억원"(붙여쓰기)이 있으면 "단위 표기 오류: '억원'은 '억 원'으로 띄어써야 함"
- 콤마·소수점에 붙지 않은 5자리 이상 숫자(정규식 (?<![\d,.])\d{5,}(?![\d,]))가 있으면 "천 단위 구분 콤마 누락 의심: 콤마 없는 5자리 이상 숫자 발견"
- "비중" 뒤 10자 이내에 증가·감소·확대·축소가 있는데 문서 전체에 "%p"가 없으면 "비중(구성비) 변화 표현에는 %p 표기가 필요한지 확인 필요"
cross_check_all_numbers(final_text: str, data: dict) -> dict
- ★ 기존 find_unverified_numbers를 재사용해 {"통과": 불일치가 없으면 True, "불일치수치": [...]}를 돌려준다.
review_press_release(final_text: str, data: dict) -> list
- 근거자료 = data에서 "계산지표", "통계해석결과", "품목별지표", "역대최대여부", "최근3개월증감률" 중 있는 것만 모은 dict
- 프롬프트: 통계 보도자료 전문 감수자로서 원본 데이터와 보도자료를 대조해 수치 오류, 과장된 표현, 문체 불일치, 논리적 비약을 지적.
  지적은 최대 5건, 항목당 한 문장. 문제가 없으면 빈 배열 []. 원본 데이터는 json.dumps(근거자료, ensure_ascii=False)로 넣는다.
  JSON 배열로만 답하게 하고 예시 [{"유형": "...", "위치": "...", "지적사항": "..."}]를 보여 준다.
- call_claude(prompt, system="당신은 통계 보도자료 전문 감수자입니다.", max_tokens=2000) → parse_json_response.
- ★ 파싱에 실패하면(ValueError, json.JSONDecodeError) 예외를 내지 말고
  [{"유형": "감수 응답 파싱 실패", "위치": "-", "지적사항": "AI 감수 응답이 잘리거나 JSON 형식이 아니어서 자동으로 해석하지 못했습니다."}]를 돌려준다.
```

**프롬프트의 ★ 항목과, 빠지면 생기는 문제**

| ★ 항목 | 빠지면 생기는 문제 |
| --- | --- |
| 수치·표기 변경 금지 | 문장을 다시 쓰며 "20조 1,250억 원"처럼 바꿔 수치 교차 검증이 실패함(슬라이드 11: 문체 변환 과정의 새 오류) |
| 머리말 없이 본문만 | "다음은 통일한 초안입니다:" 같은 문장이 최종본에 섞임 |
| `find_unverified_numbers` 재사용 | 요약 검증과 최종본 검증의 기준이 달라짐(슬라이드 13 노트) |
| 감수 파싱 실패 시 안내 항목 | 응답이 잘리면 예외로 전체 파이프라인이 멈추고 앞 단계 검수 결과까지 잃음(슬라이드 16 노트) |

## 6. 검증 (핵심, 비용 0)

```python
# 검증 Ch09 — 가짜 응답으로 구조 확인 (비용 0)
import sys, json
from types import SimpleNamespace as NS
sys.path.insert(0, ".")
import mywork.write as W
from mywork.review import check_formatting_errors, cross_check_all_numbers, review_press_release

with open("mywork/press_data.json", encoding="utf-8") as f:
    data = json.load(f)

# ① 초안 조립 (리드문 + 본문 단락, 빈 줄로 구분)
draft = W.assemble_full_text(data)
assert draft.startswith(data["헤드라인"]["리드문"] + "\n\n"), "리드문 뒤에 빈 줄이 없음"
assert all(p["내용"] in draft for p in data["본문"]), "본문 단락이 빠짐"

# ② 표기 검수 (정규식 1차 필터)
나쁜 = "거래액은 201250억원으로 집계되었다. 의류 비중은 전월보다 확대되었다."
오류 = check_formatting_errors(나쁜)
for e in 오류:
    print("표기 오류:", e)
assert len(오류) == 3, "억원·콤마·%p 세 가지를 모두 잡지 못함"
정상 = f"거래액은 {data['계산지표']['총거래액']:,}억 원으로 전월 대비 {data['계산지표']['전월대비증감률']}% 증가하였다."
assert check_formatting_errors(정상) == [], "정상 문장에서 오류가 나옴"

# ③ 전체 수치 교차 검증
print("교차 검증(정상):", cross_check_all_numbers(정상, data))
assert cross_check_all_numbers(정상, data)["통과"] is True
틀림 = cross_check_all_numbers(정상 + " 상위 세 품목이 전체의 82.0%를 차지하였다.", data)
print("교차 검증(파생 수치 추가):", 틀림)
assert 틀림 == {"통과": False, "불일치수치": ["82.0"]}
print("현재 초안의 자동 검수:", check_formatting_errors(draft) or "표기 문제 없음", "|", cross_check_all_numbers(draft, data))

# ④ 문체 통일과 AI 감수 (가짜 응답)
받은 = []
응답 = iter([draft,
            '[{"유형": "문체 불일치", "위치": "본문 2단락", "지적사항": "개조식 표현이 남아 있음"}]',
            '[{"유형": "과장된 표현", "위치": "부제", "지적사항": "잘린 응답'])
def fake_create(**kwargs):
    받은.append(kwargs)
    return NS(stop_reason="end_turn", content=[NS(type="text", text=next(응답))])
W.client.messages.create = fake_create
최종본 = W.unify_style(draft)
assert "변경" in 받은[0]["messages"][0]["content"] and draft in 받은[0]["messages"][0]["content"]
지적 = review_press_release(최종본, data)
assert 지적[0]["유형"] == "문체 불일치"
assert "계산지표" in 받은[1]["messages"][0]["content"] and "통계해석결과" in 받은[1]["messages"][0]["content"], "근거자료 누락"
실패 = review_press_release(최종본, data)
print("감수 파싱 실패 시:", 실패)
assert 실패[0]["유형"] == "감수 응답 파싱 실패"
print("Ch09 OK — 문체 통일·3단계 검수 구조 검증 통과 (실제 API 호출은 8절)")
```

## 7. 관찰 — 정규식 검수가 잡는 것과 못 잡는 것

# 관찰 Ch09
import sys

for s in ["거래액은 201,250억 원이다.",

**예시 출력**

```text
문제 없음 ← 거래액은 201,250억 원이다.
["단위 표기 오류: '억원'은 '억 원'으로 띄어써야 함"] ← 거래액은 201,250억원이다.
['천 단위 구분 콤마 누락 의심: 콤마 없는 5자리 이상 숫자 발견'] ← 2026년 거래액은 201250억 원이다.
문제 없음 ← 의류 비중이 3%p 확대되었다.
['비중(구성비) 변화 표현에는 %p 표기가 필요한지 확인 필요'] ← 의류 비중이 3% 확대되었다.
문제 없음 ← 거래액이 3%p 증가하였다.
```

**무엇을 설명할까**: 마지막 문장은 **증감률에 %p를 잘못 쓴** 오류인데 통과합니다. 정규식 검수는 1차 필터일 뿐이고(슬라이드 12 노트), AI 감수와 **사람의 최종 확인**(슬라이드 18~19)이 함께 있어야 합니다.

## 8. 실제 API 호출 (권장, 2회)

```python
# 선택 Ch09 — 실제 Claude API로 문체 통일 + 3단계 검수 (2회, 비용 발생)
import sys, json
sys.path.insert(0, ".")
from mywork.write import assemble_full_text, unify_style
from mywork.review import check_formatting_errors, cross_check_all_numbers, review_press_release

with open("mywork/press_data.json", encoding="utf-8") as f:
    data = json.load(f)
최종본 = unify_style(assemble_full_text(data))
print(최종본)
검수결과 = {
    "표기오류검사": check_formatting_errors(최종본),
    "수치교차검증": cross_check_all_numbers(최종본, data),
    "AI감수지적사항": review_press_release(최종본, data),
}
print(json.dumps(검수결과, ensure_ascii=False, indent=2))
data["최종본"], data["검수결과"] = 최종본, 검수결과
with open("mywork/press_data.json", "w", encoding="utf-8") as f:
    json.dump(data, f, ensure_ascii=False, indent=2)
print("최종본·검수결과 저장")
```

`표기오류검사`가 `[]`, `수치교차검증`의 `통과`가 `True`이면 자동 검수는 통과입니다. `AI감수지적사항`은 **참고**입니다 — 타당한 지적만 골라 고치고, 고친 뒤에는 수치 교차 검증을 다시 실행합니다(슬라이드 18의 반영 절차).

## 10. 문제 해결

| 증상 | 원인 | 조치 |
| --- | --- | --- |
| `억원·콤마·%p 세 가지를 모두 잡지 못함` | 정규식 조건 누락 | 오류 메시지와 출력을 붙여 수정 요청 |
| `정상 문장에서 오류가 나옴` (콤마 누락 의심) | "201,250"의 뒷부분을 5자리 숫자로 오인 | "콤마·소수점에 붙지 않은 5자리 이상 숫자만 잡도록 (?<![\d,.])\d{5,}(?![\d,]) 를 써줘" 요청 |
| `ImportError: cannot import name 'call_claude'` | 4차시 `write.py`에 `call_claude`가 없음 | 4차시 9절 폴백으로 `write.py` 교체 후 다시 |
| `ImportError ... circular import` | `write.py`가 `review.py`를 import 함 | "write.py에서 review import를 빼줘" 요청(review → write 방향만) |
| 감수 파싱 실패 시 예외로 멈춤 | try/except 누락 | 프롬프트의 ★ 문장을 붙여 수정 요청 |
| 최종본 앞에 "다음은 …입니다" 문장이 붙음 | 출력 형식 조건 누락 | "머리말 없이 본문만 출력"을 프롬프트에 넣도록 요청 |
| `KeyError: '헤드라인'` / `'본문'` | 7·8차시 실제 호출을 건너뜀 | 2절 준비 코드 실행 |
