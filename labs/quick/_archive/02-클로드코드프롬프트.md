# Claude Code로 코드 만들기 — 차시별 프롬프트 (10분 트랙)

이 문서는 `labs/quick/01-검토와진행안.md`의 10분 실습에서 **미리 만들어진 파이썬 코드를 실행하는 대신, Claude Code에게 프롬프트를 주어 같은 기능의 코드를 직접 만들게** 하기 위한 프롬프트 모음입니다.

- 각 프롬프트는 프로젝트의 기존 `modules/` 코드가 하는 일을 처음 보는 사람이 프롬프트만 읽고도 재현할 수 있도록 쓴 것입니다.
- 프롬프트마다 "**★**" 표시가 붙은 줄은 이 프로젝트에서 실제로 겪은 버그·함정에서 나온 항목입니다. 빠지면 같은 문제가 다시 생깁니다(근거는 각 차시의 표 참고).
- "**★기존과 다른 요구**"로 표시한 줄은 기존 `modules/` 코드와 일부러 다르게 요구한 개선입니다(01번 문서 7절에서 채택 여부를 정합니다).

---

## 사용법 (공통)

1. **프로젝트 루트**에서 Claude Code를 실행합니다(루트의 `CLAUDE.md`가 자동으로 적용됩니다).
2. 새 세션이면 아래 **공통 머리말**을 먼저 한 번 붙여 넣고, 그다음 차시 프롬프트를 붙여 넣습니다.
3. 파일 쓰기 승인 요청이 뜨면 승인합니다. 생성 위치는 전부 `mywork/` 패키지 안입니다(기존 `modules/`는 건드리지 않음).
4. 프롬프트 바로 아래의 **검증 스니펫**을 실행해 기대 결과와 비교합니다(`python 파일` 또는 파이썬 대화형에 붙여 넣기).
5. 생성이 3분 넘게 걸리거나 검증이 끝내 통과하지 않으면(차시 시작 후 약 4분 시점) **폴백**: 기존 파일을 복사해 다음 단계로 넘어갑니다. 복사 명령은 차시별로 적어 두었습니다.

   **5-1. 폴백 공통 후처리** (폴백으로 파일을 복사한 직후 1회, 프로젝트 루트에서 실행): 기존 `modules/*.py`는 서로를 `modules.`로 import 하므로, 그대로 두면 복사한 `mywork/review.py` 등이 여러분이 만든 `mywork/write.py`가 아니라 기존 `modules/write.py`(실제 API 클라이언트)를 불러옵니다. 아래 명령으로 설정 파일을 함께 복사하고 import 경로를 `mywork.`로 바꿉니다(`main.py`가 쓰는 `modules.export`만 그대로 둡니다).

   ```powershell
   if (-not (Test-Path mywork\config.py)) { Copy-Item modules\config.py mywork\config.py }
   Get-ChildItem mywork\*.py | ForEach-Object {
       (Get-Content $_.FullName -Raw -Encoding UTF8) -replace 'from modules\.io','from mywork.data_io' -replace 'from modules\.(?!export)','from mywork.' | Set-Content $_.FullName -Encoding UTF8
   }
   ```

6. (선택, 실습 종료 후) 만든 코드와 기존 코드를 비교해 보세요: `git diff --no-index modules/nlp.py mywork/nlp.py`

> 실행 위치: 모든 명령과 스니펫은 프로젝트 루트에서 실행합니다. `mywork/` 안으로 들어가 실행하지 마세요(`io.py` 같은 이름이 파이썬 표준 라이브러리와 충돌하는 것을 피하려고 입력 모듈 이름을 `data_io.py`로 했습니다).

### 공통 머리말 (세션 시작 시 1회 붙여넣기)

~~~text
[이 프로젝트의 공통 규칙 — 앞으로 만드는 모든 코드에 적용]
1. 수치 계산(증감률·비중·순위·합계)은 반드시 파이썬 함수가 한다. LLM에게 계산을 시키지 않는다.
2. API 키를 코드에 직접 쓰지 않는다. .env에서 python-dotenv로 읽는다(ANTHROPIC_API_KEY, PUBLIC_API_KEY).
3. LLM이 쓴 문장 속 숫자는 원본 데이터와 교차 검증한다.
4. 문장은 객관적 서술체("~하였다")의 공공 보도자료체로 쓴다.
5. Claude 모델 ID는 mywork/write.py의 MODEL_NAME 상수 한 곳에만 둔다.
6. 결과 파일은 mywork/ 패키지 안에만 만든다. 기존 modules/, tests/, main*.py는 열어보거나 복사하지 말고, 이 프롬프트의 설명만으로 직접 작성한다.
7. 요청하지 않은 기능·예외처리·주석·문서 파일은 추가하지 않는다. 함수 이름과 시그니처는 지시한 그대로 쓴다.
8. mywork 안의 모듈끼리는 `from mywork.config import ...` 처럼 절대 경로로 import 한다.
9. 파일을 만든 뒤 `python -c "import mywork.<모듈>"`로 import 오류가 없는지만 확인하고 끝낸다.
~~~

## 2차시 — 정제·표준화·구조화 (`mywork/config.py`, `mywork/clean.py`)

**10분 배분**: 0:00 입력 확인 · 1:00 프롬프트→생성 · 4:00 검증 스니펫 · 7:00 마스킹 실험 · 9:00 저장 확인

~~~text
mywork/ 폴더에 다음 3개 파일을 만들어줘. (mywork/__init__.py 는 빈 파일)

[mywork/config.py]  — 데이터 딕셔너리(항목 정의)를 상수로 둔다.
- PRIMARY_INDICATOR = "총거래액", PRIMARY_UNIT = "억 원"
- REQUIRED_FIELDS = ["총거래액", "전월대비증감률", "전년동월대비증감률"]   # 제목·리드문에 반드시 들어가는 필수 항목
- INDICATOR_UNITS = {"총거래액": "억 원", "전월대비증감률": "%", "전년동월대비증감률": "%"}

[mywork/clean.py]
mask_sensitive_info(text: str) -> str
- 주민등록번호(예: 900101-1234567)는 "******-*******"로, 휴대전화(010/011/016/017/018/019로 시작, 앞 3자리 - 가운데 3~4자리 - 뒤 4자리, 예: 010-1234-5678, 011-123-4567)는 "010-****-****"로 치환한다. 정규표현식 사용.

clean_and_structure(raw: dict) -> dict
- 입력 raw 키: 제목, 공표일자, 자료출처(없을 수 있음), 계산지표(dict), 핵심내용(list), 원문(str)
- 원문 정제: (1) 연속 공백·줄바꿈을 공백 하나로 (2) 앞뒤 공백 제거 (3) "(주:...)" 형태의 괄호 주석 제거
- 원문 표준화: 숫자 바로 뒤의 "억원"→"억 원", "백만원"→"백만 원". 그다음 mask_sensitive_info를 적용한다.
- 반환 구조(키 이름은 한글 그대로):
  {"문서정보": {"제목", "공표일자", "자료출처"(없으면 "공공데이터포털 Open API")},
   "계산지표": raw["계산지표"] 그대로, "핵심내용": raw["핵심내용"] 그대로, "원문": 정제된 문장}
- ★ 계산지표는 다시 계산하거나 바꾸지 말고 그대로 옮긴다. 이 함수는 구조만 표준화하고 계산은 하지 않는다(계산은 5차시 stats가 담당).
- raw에 "품목별지표", "역대최대여부", "최근3개월증감률", "월별이력"이 있으면 계산 없이 그대로 결과에 함께 전달한다.
~~~

| 프롬프트에 꼭 들어간 것 | 빠지면 생기는 문제 |
| --- | --- |
| 계산지표를 그대로 통과(계산 금지) | 정제 단계에서 값이 바뀌면 이후 모든 수치 검증의 기준이 흔들림(CLAUDE.md 원칙 1) |
| 단위 표준화 "억원→억 원" | 9차시 `check_formatting_errors`의 단위 표기 검사에 걸림 |
| 마스킹을 정제 안에서 항상 적용 | 통계 원문에 섞인 담당자 연락처가 LLM으로 전송됨(1차시 보안 원칙) |
| 표준 구조 키 이름을 한글 그대로 | 3~10차시 모든 코드가 이 키(`문서정보`, `계산지표`…)를 그대로 읽음 |

## 3차시 — 키워드·주요 문장 추출 (`mywork/nlp.py`)

**10분 배분**: 0:00 입력 확인 · 1:00 프롬프트→생성 · 4:00 검증 스니펫 · 6:00 "왜 '거래액'이 빠졌나" 관찰 · 8:00 저장

~~~text
mywork/nlp.py 를 만들어줘. 한국어 보도자료 원문에서 키워드와 주요 문장을 통계·규칙 기반으로 뽑는 모듈이다(생성형 AI 사용 금지). 사용 라이브러리: kiwipiepy, scikit-learn, networkx (이미 설치됨).

모듈 전역:
- Kiwi()는 한 번만 만든다(초기화 비용이 큼).
- ★ 그 Kiwi에 add_user_word(단어, "NNP", 0.0)로 ["온라인쇼핑", "모바일쇼핑", "거래액", "역대급"]을 등록한다. (등록하지 않으면 "온라인쇼핑"이 "온라인"+"쇼핑"으로 쪼개져 핵심 소재가 사라진다)
- STOPWORDS = {"등", "및", "수", "것"}

함수(이름·시그니처 그대로):
1. extract_nouns(text) -> list : 형태소 분석 후 품사 태그가 "NN"으로 시작하는 토큰의 form만 반환.
2. clean_keywords(keyword_scores, top_n=5) -> list[(단어, 점수)] : 불용어와 한 글자 단어를 제외하고 점수 내림차순 상위 top_n개.
3. split_sentences(text) -> list : 마침표·느낌표·물음표 뒤의 공백을 기준으로 문장 분리(정규식 lookbehind), 빈 문장 제거.
4. extract_keywords_tfidf(text, top_n=5) -> list[(단어, 점수)] :
   - ★ 원문은 1건뿐이라 다른 문서와 비교하는 IDF가 무의미하다. 그래서 원문을 문장으로 나눠 "각 문장을 하나의 문서"로 취급한다.
   - 문장별로 명사만 공백으로 이어붙인 문자열 목록(빈 것 제외, 없으면 [] 반환)을 TfidfVectorizer에 넣는다.
   - 단어의 대표 점수 = 그 단어의 문장별 TF-IDF 점수 중 최댓값(열 방향 max). 그 결과를 clean_keywords로 넘겨 반환.
5. extract_main_sentences(sentences, ratio=0.5) -> list : TextRank
   - 문장이 1개 이하면 그대로 반환.
   - 문장별 명사 문자열(명사가 없으면 문장 원문)을 TF-IDF 벡터화 → 코사인 유사도 행렬.
   - ★ 유사도 행렬의 대각선(자기 자신과의 유사도 1.0)은 반드시 0으로 만든다(안 그러면 self-loop가 점수를 왜곡한다).
   - networkx.from_numpy_array로 그래프를 만들고 pagerank 점수를 구한다.
   - 상위 max(1, round(문장수*ratio))개를 뽑되, ★ 반환은 원문에 등장한 순서로 정렬하고 문장을 새로 쓰거나 고치지 않고 원문 그대로 돌려준다(원문과 대조 검증이 가능하고, 이 단계에서는 환각이 생길 수 없다).
6. filter_sentences_by_keywords(sentences, keywords) -> list : 키워드 중 하나라도 문장에 포함되면 남긴다.
7. analyze_document(raw_text, standard_data) -> dict : 위 함수를 조합해 standard_data["NLP분석결과"] = {"핵심키워드": [단어 목록], "주요문장": [최종 필터를 통과한 문장 목록]} 을 채우고 standard_data를 반환.
~~~

   - abs(momRate) >= 5 → 양수면 "전월 대비 큰 폭 증가", 음수면 "전월 대비 큰 폭 감소"
   - abs(yoyRate) >= 5 → 양수면 "전년동월 대비 큰 폭 증가", 음수면 "전년동월 대비 큰 폭 감소"
   - recent_momRates가 3개 이상이면 마지막 3개가 모두 양수 → "최근 3개월 연속 증가세", 모두 음수 → "최근 3개월 연속 감소세"
2. generate_interpretation(indicator_name, value, unit, point_type) -> str
   특이점 유형별 문장 템플릿 딕셔너리로 문장을 만든다. 지원 유형 8개: "역대 최대치 경신", "전월 대비 큰 폭 증가", "전월 대비 큰 폭 감소", "전년동월 대비 큰 폭 증가", "전년동월 대비 큰 폭 감소", "최대 비중", "최근 3개월 연속 증가세", "최근 3개월 연속 감소세". 없는 유형이면 "" 반환.
   문장은 보도자료체("~하였다", "~이어가고 있다")로 쓴다. 예: "{지표명}이 전월 대비 {값}% 증가하며 큰 폭의 상승세를 보였다." / 감소는 "...감소하며 큰 폭의 하락세를 보였다."
   ★기존과 다른 요구: "역대 최대치 경신"과 "최대 비중" 문장의 값은 천 단위 콤마로 표기하고 조사는 자연스럽게 쓴다(예: "온라인쇼핑 거래액은 201,250억 원으로 역대 최대치를 기록하였다."). 지표명은 받침이 있는 "온라인쇼핑 거래액"으로 쓸 것이므로 조사는 "은/이"로 고정해도 된다.
3. _shift_month(ym, delta_months) -> str : "YYYY-MM" 문자열을 delta_months(음수면 과거)만큼 이동해 같은 형식으로 반환(연 경계 처리).
4. derive_history_indicators(history, current_ym, current_value) -> dict
   - history = [{"연월": "YYYY-MM", "값": 숫자}, ...] (순서 무관, 이번 달 제외)
   - 반환 키 4개: "역대최대여부", "최근3개월증감률", "전월대비증감률", "전년동월대비증감률"
   - history가 비어 있으면 {"역대최대여부": True, "최근3개월증감률": [], "전월대비증감률": None, "전년동월대비증감률": None}
   - ★ 역대최대여부는 "같은 달"(예: 1월)의 과거 값들과만 비교해서, 이번 값이 그 최댓값 이상이면 True(같은 달 과거값이 없으면 True). 월별 규모가 원래 다르므로(명절 등) 다른 달과 섞어 비교하지 않는다.
   - 최근3개월증감률: history와 이번 달을 연월순으로 정렬한 뒤 마지막 3개 구간의 "직전 대비 증감률(%)" 리스트, 소수 첫째 자리 반올림. 직전 값이 0이거나 없으면 그 구간은 건너뛴다.
   - ★ 전월/전년동월 증감률: 비교 기준 연월이 history에 없으면 0이나 임의값으로 채우지 말고 None. 있으면 (이번-기준)/기준*100을 소수 첫째 자리로 반올림.
5. build_interpretation_sentences(특이점, 계산지표, 지표명) -> list[str]
   특이점 목록의 각 항목을 generate_interpretation으로 문장화해 리스트로 반환. 모든 문장의 주어는 지표명.
   - "역대 최대치 경신"에는 계산지표[PRIMARY_INDICATOR]와 PRIMARY_UNIT을 쓴다.
   - ★ 전월 대비는 계산지표["전월대비증감률"], 전년동월 대비는 계산지표["전년동월대비증감률"]을 각각 써서 서로 섞지 않는다.
   - ★ 감소 방향은 abs()로 부호를 뗀 값을 감소 전용 템플릿에 채운다(부호를 두면 "-6% 감소"처럼 이중 부정이 된다).
   - "최근 3개월 연속 증가세/감소세"는 값 없이 문장만 만든다.
6. add_calculated_indicators(data, indicator_name="온라인쇼핑 거래액") -> dict
   - data["계산지표"], data.get("역대최대여부", False), data.get("최근3개월증감률")로 detect_special_points를 호출한다(momRate=전월대비증감률, yoyRate=전년동월대비증감률).
   - ★기존과 다른 요구: 지표명을 제목의 마지막 단어에서 뽑지 말고 indicator_name 인자로 받는다(제목이 "…동향"으로 끝나면 "동향은 …"처럼 어색한 문장이 나오기 때문).
   - data["통계해석결과"] = {"특이점목록": [...], "해석문장": [...]} 를 저장하고 data를 반환.

  해당하는 메시지 문자열만 리스트로 반환(없으면 []).
- review_press_release(final_text, data) -> list[dict] : AI 제3자 감수.
  * ★ 근거자료 = data 중 "계산지표", "통계해석결과", "품목별지표", "역대최대여부", "최근3개월증감률" 키(있는 것만)를 골라 만든 dict. 이것을 프롬프트에 json.dumps(ensure_ascii=False)로 함께 준다. (계산지표만 주면 감수자가 "역대 최대", "3개월 연속 증가" 같은 표현을 근거 없는 과장으로 오판한다)
  * 프롬프트: "통계 보도자료 전문 감수자" 역할, 수치 오류·과장된 표현·문체 불일치·논리적 비약을 지적, ★"지적사항은 최대 5건까지, 항목당 한 문장"으로 제한, JSON 배열로만 답하라: [{"유형": "...", "위치": "...", "지적사항": "..."}]
  * ★ max_tokens=1500 (짧으면 응답이 중간에 잘려 JSON 파싱이 깨진다)
  * ★ parse_json_response가 ValueError(json.JSONDecodeError 포함)를 던지면 예외를 밖으로 던지지 말고 [{"유형": "감수 응답 파싱 실패", "위치": "-", "지적사항": "AI 감수 응답이 잘리거나 JSON 형식이 아니어서 자동으로 해석하지 못했습니다."}]를 반환한다. (AI 감수는 안전장치 3단계 중 하나일 뿐이므로 이 단계가 실패해도 전체 파이프라인이 멈추면 안 된다)
