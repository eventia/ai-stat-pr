# Ch 08 실습. 통계 보도자료 작성 실습2 (그래프 설명)

> 이 문서는 강의(PPT) 자료가 아니라, 직접 손으로 따라 하는 실습 가이드입니다. **실습은 이 문서를 기준으로 진행**하고, 개념 설명이 더 필요할 때만 강의안을 참고하세요.
> - 개념 설명(강의안): [../lect/CH-08-Content.md](../lect/CH-08-Content.md)
> - **실행 위치**: 모든 명령어는 프로젝트 루트 폴더에서 실행합니다.
> - **사전 준비**: [data/processed/press_data.json](../data/processed/press_data.json)에 `시각자료설명`이 있어야 합니다(6차시 7단계 완료 필요). `.env`에 `ANTHROPIC_API_KEY` 필요.
> - **비용·비결정성 안내**: 4차시와 동일합니다.

## 실습 목표

- 6차시에서 만든 그래프 설명문을 소주제별로 정리한다.
- 짧은 설명문을 두괄식 구조의 본문 단락(3~4문장)으로 확장한다.
- 여러 단락을 연결어로 자연스럽게 이어 붙여 본문 전체를 완성한다.

담당 코드: [../modules/write.py](../modules/write.py) (`expand_to_paragraph`, `generate_body_paragraphs`)
담당 테스트: 별도 테스트 파일 없음 — 이 함수들은 LLM을 호출하므로 [tests/test_ch10_pipeline.py](../tests/test_ch10_pipeline.py)가 Claude 응답을 가짜(mock)로 대체해 배선만 검증합니다.

## 이 실습으로 만들어지는 것

- [data/processed/press_data.json](../data/processed/press_data.json)에 **`본문`**(소주제별 단락 목록) 필드가 추가된 버전

## 0단계. 표준 데이터 불러오고 그래프 설명 소재 확인하기

> 개념 참고: 강의안 소주제 1 (페이지 6~8, 설명 소재를 소주제 단위로 정리)

```python
import sys, json
sys.path.insert(0, ".")

with open("data/processed/press_data.json", encoding="utf-8") as f:
    data = json.load(f)

소재목록 = [(항목["소주제"], 항목["설명문"]) for 항목 in data["시각자료설명"]]
for subtopic, fact in 소재목록:
    print(subtopic, "→", fact)
```

**예상 출력** (6차시 결과를 그대로 이어받았다면)

```
품목별 동향 → 의류이 65,000억 원으로 가장 높았으며, 가전이 52,000억 원으로 그 뒤를 이었다...
품목별 비중 → 품목별 비중을 살펴보면 의류이 전체의 32.3%로 가장 큰 비중을 차지하였으며...
시계열 동향 → 온라인쇼핑 거래액은 2025-10부터 2026-01까지 증가세를 보이고 있으며...
```

이 목록의 `소주제`가 6차시에서 `시각자료설명` 각 항목에 넣어둔 필드입니다. 이번 실습은 이 소주제 하나당 본문 단락 하나를 만드는 것이 목표입니다.

---

## 1단계. (실제 비용 발생) 짧은 설명문을 본문 단락으로 확장하기

> 개념 참고: 강의안 소주제 2 (페이지 10~11, 두괄식 구조 프롬프트, `expand_to_paragraph`)

```python
from modules.write import expand_to_paragraph

paragraphs = []
for subtopic, fact in 소재목록:
    본문단락 = expand_to_paragraph(subtopic, fact)
    paragraphs.append(본문단락)
    print(f"[{subtopic}]\n{본문단락}\n")
```

**예시 실행 결과** (실제로 한 번 실행해 확인한 값 — 표현은 매번 달라질 수 있습니다)

```
[품목별 동향]
품목별로는 의류가 65,000억 원으로 가장 많이 거래되어 1위를 차지하였고, 가전이
52,000억 원으로 그 뒤를 이었다. 반면 기타 품목은 10,000억 원으로 가장 낮은
거래액을 기록하였다.

[품목별 비중]
품목별 비중을 살펴보면 의류가 전체의 32.3%로 가장 큰 비중을 차지하였으며,
가전(25.8%), 식품(23.9%)이 뒤를 이어 상위 세 품목이 전체의 82.0%를 차지하였다.
```

`expand_to_paragraph`는 소주제와 설명 소재 두 가지만 받는 범용 함수입니다 — 지표명(온라인쇼핑, 총거래액 등)에 전혀 의존하지 않으므로, 나중에 다른 통계표를 다루더라도 수정 없이 그대로 재사용할 수 있습니다.

## 2단계. 연결어로 단락 잇고 수치 검증하기

> 개념 참고: 강의안 페이지 12~13 (연결어 처리)

```python
from modules.review import verify_numbers

연결어_목록 = ["", "한편, ", "아울러, "]
for i in range(1, len(paragraphs)):
    paragraphs[i] = 연결어_목록[min(i, len(연결어_목록) - 1)] + paragraphs[i][0].lower() + paragraphs[i][1:]

full_body = "\n\n".join(paragraphs)
print(full_body)
print()
for p in paragraphs:
    print(verify_numbers(p, data))
```

두 번째 단락부터 "한편, ", "아울러, " 같은 연결어가 자연스럽게 붙었는지, 모든 단락이 수치 검증을 통과했는지(`True`) 확인합니다.

## 3단계. `generate_body_paragraphs`로 전체 과정 한 번에 실행하기 (실제 비용 발생)

> 개념 참고: 강의안 페이지 14 (통합 함수)

1~2단계에서 손으로 진행한 반복문·연결어 처리를 실제 파이프라인은 함수 하나로 처리합니다. 아래를 실행하면 API를 한 번 더 호출하게 되므로, 이미 1단계를 실행했다면 굳이 다시 실행하지 않아도 됩니다 — 결과 형태만 확인하면 됩니다.

```python
from modules.write import generate_body_paragraphs

본문 = generate_body_paragraphs(data)
for 단락 in 본문:
    print(f"[{단락['소주제']}]")
    print(단락["내용"])
    print()
```

`generate_body_paragraphs`는 손으로 만든 `소재목록` 대신 `data["시각자료설명"]`을 직접 읽어, 각 항목의 `소주제`와 `설명문`으로 `expand_to_paragraph`를 반복 호출하고, 연결어까지 붙여 `{"소주제": ..., "내용": ...}` 형태의 표준 "본문" 스키마로 반환합니다.

## 완성도 점검

1. 각 단락이 두괄식 구조(핵심 수치 먼저)로 시작하는가
2. 단락 간 연결어가 자연스럽고 중복되지 않는가
3. 모든 단락이 `verify_numbers` 검증을 통과하였는가
4. 7차시의 리드문과 본문 내용이 서로 모순되지 않는가
