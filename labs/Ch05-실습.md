## 1단계. pandas로 증감률·비중·순위 계산하기

> 개념 참고: 강의안 소주제 1 (페이지 7~10)

2차시 표준 데이터는 온라인쇼핑 "총거래액" 하나만 다루지만, 실제 보도자료에는 품목별 세부 데이터도 함께 실립니다. 아래는 품목별 데이터를 새로 만들어 계산을 실습하는 예시입니다.

```python
import pandas as pd

category_df = pd.DataFrame({
    "품목": ["의류", "가전", "식품", "생활용품", "기타"],
    "당월거래액": [65000, 52000, 48000, 26250, 10000],
    "전월거래액": [64200, 48500, 45100, 26800, 9676],
})

category_df["전월대비증감률"] = (
    (category_df["당월거래액"] - category_df["전월거래액"]) / category_df["전월거래액"] * 100
).round(1)
category_df["비중"] = (category_df["당월거래액"] / category_df["당월거래액"].sum() * 100).round(1)
category_df["순위"] = category_df["당월거래액"].rank(ascending=False).astype(int)
print(category_df)
```

**실제 실행 결과** (myvenv에서 직접 검증 — 비중 합계가 정확히 100.0%가 되는지 확인)

```
     품목  당월거래액  전월거래액  전월대비증감률   비중  순위
0    의류  65000  64200      1.2  32.3   1
1    가전  52000  48500      7.2  25.8   2
2    식품  48000  45100      6.4  23.9   3
3  생활용품  26250  26800     -2.1  13.0   4
4    기타  10000   9676      3.3   5.0   5
```

생활용품만 유일하게 감소(-2.1%)했다는 점이 눈에 띕니다. 이 감소 케이스는 3단계에서 중요한 역할을 합니다.

## 2단계. 특이점 자동 탐지하기

> 개념 참고: 강의안 소주제 2 (페이지 13~14, 임계값 5%·역대 최대·연속 추세 3가지 규칙)

```python
from modules.stats import detect_special_points

# 품목별로 증감률 임계값(5%) 기준 특이점 확인
for _, row in category_df.iterrows():
    if abs(row["전월대비증감률"]) >= 5:
        방향 = "증가" if row["전월대비증감률"] > 0 else "감소"
        print(f"{row['품목']} 거래액이 전월 대비 {abs(row['전월대비증감률'])}% 큰 폭 {방향}")

# 온라인쇼핑 총거래액 기준 특이점 탐지 (2차시 계산지표 사용)
지표 = data["계산지표"]
특이점 = detect_special_points(
    momRate=지표["전월대비증감률"],
    yoyRate=지표["전년동월대비증감률"],
    is_record_high=True,
    recent_momRates=[2.0, 1.8, 1.5],
)
print(특이점)
```

**실제 실행 결과**

```
가전 거래액이 전월 대비 7.2% 큰 폭 증가
식품 거래액이 전월 대비 6.4% 큰 폭 증가
['역대 최대치 경신', '전년동월 대비 큰 폭 증가', '최근 3개월 연속 증가세']
```

생활용품의 -2.1%는 임계값(5%) 미만이라 특이점 목록에 잡히지 않습니다 — "특이점"은 모든 변화가 아니라 언급할 만큼 중요한 변화만 골라내는 것이 목적이기 때문입니다.

## 3단계. 감소 케이스까지 포함한 해석 문장 생성하기

> 개념 참고: 강의안 소주제 3 (페이지 16~17, 문장 템플릿 설계)

```python
from modules.stats import generate_interpretation, check_percent_unit

print(generate_interpretation("가전 거래액", 7.2, "%", "전월 대비 큰 폭 증가"))
print(generate_interpretation("생활용품 거래액", 2.1, "%", "전월 대비 큰 폭 감소"))
print("%p 표기 검증:", check_percent_unit("가전 거래액이 전월 대비 7.2% 증가하며 큰 폭의 상승세를 보였다.", is_rate_of_rate=False))
```

**실제 실행 결과**

```
가전 거래액이 전월 대비 7.2% 증가하며 큰 폭의 상승세를 보였다.
생활용품 거래액이 전월 대비 2.1% 감소하며 큰 폭의 하락세를 보였다.
%p 표기 검증: True
```

**확인할 점**: 감소 문장에서 "-2.1% 감소"처럼 이중 부정이 되지 않고 "2.1% 감소"로 자연스럽게 나옵니다. `generate_interpretation`을 직접 호출할 때는 항상 `abs()`로 부호를 뗀 값을 넘겨야 하며, 실제 파이프라인 함수(`build_interpretation_sentences`)는 이 처리를 자동으로 해 줍니다.

> `check_percent_unit`은 %와 %p 표기를 검증하는 함수지만, 정의만 되어 있을 뿐 `add_calculated_indicators`를 포함해 다른 어떤 파이프라인 코드에서도 자동으로 호출되지 않습니다. 필요하다면 9단계의 `check_formatting_errors`(9차시)처럼 직접 호출해서 참고용으로만 사용하십시오.

## 4단계. 과거 이력만으로 역대 최대 여부 자동 계산하기

> 개념 참고: 강의안 페이지 12, 22 (역대 최고·최저 판별, `derive_history_indicators`)

```python
from modules.stats import derive_history_indicators

history = [
    {"연월": "2024-01", "값": 175320},
    {"연월": "2025-01", "값": 189430},
    {"연월": "2025-11", "값": 195000},
    {"연월": "2025-12", "값": 198276},
]
계산됨 = derive_history_indicators(history, "2026-01", 201250)
print(json.dumps(계산됨, ensure_ascii=False, indent=2))
```

**실제 실행 결과**

```json
{
  "역대최대여부": true,
  "최근3개월증감률": [2.9, 1.7, 1.5],
  "전월대비증감률": 1.5,
  "전년동월대비증감률": 6.2
}
```

이 함수는 과거 월별 실적(`history`)과 이번 달 연월·값만 주면 "역대 최대인지"를 사람이 조사할 필요 없이 자동으로 판단합니다. 같은 달(1월)의 과거 값들만 골라 비교한다는 점에 주의하세요 — 명절이 있는 달과 없는 달처럼 월별로 거래 규모가 원래 다르기 때문입니다.

## 5단계. `add_calculated_indicators`로 전체 계산 통합하기

> 개념 참고: 강의안 페이지 21 (통합 함수)

```python
from modules.stats import add_calculated_indicators

data["역대최대여부"] = 계산됨["역대최대여부"]
data["최근3개월증감률"] = 계산됨["최근3개월증감률"]
data = add_calculated_indicators(data)
print(json.dumps(data["통계해석결과"], ensure_ascii=False, indent=2))
```

**실제 실행 결과**

```json
{
  "특이점목록": ["역대 최대치 경신", "전년동월 대비 큰 폭 증가", "최근 3개월 연속 증가세"],
  "해석문장": [
    "동향은 201250억 원로 역대 최대치를 기록하였다.",
    "거래액이 전년동월 대비 8.7% 증가하며 큰 폭의 상승세를 보였다.",
    "거래액은 최근 3개월 연속 증가세를 이어가고 있다."
  ]
}
```

**직접 발견하게 될 어색한 부분**: 첫 번째 문장의 주어가 "거래액"이 아니라 "동향"으로 나옵니다. `add_calculated_indicators`는 `data["문서정보"]["제목"].split()[-1]`(제목의 마지막 단어)을 지표명으로 자동 추출하는데, 제목이 "2026년 1월 온라인쇼핑 **동향**"으로 끝나기 때문에 "동향"이 지표명이 되어버린 것입니다. 이는 실습 실수가 아니라 **현재 코드의 실제 동작**이며, 제목이 "~동향"으로 끝나는 한 계속 재현됩니다. 실무에서는 이 문장을 그대로 쓰지 않고 사람이 검토하거나(9차시 AI 감수가 이런 어색함을 잡아낼 수 있습니다), 필요하면 `build_interpretation_sentences`를 호출할 때 지표명을 직접 지정해 우회할 수 있습니다:

```python
from modules.stats import build_interpretation_sentences

해석문장_직접지정 = build_interpretation_sentences(
    data["통계해석결과"]["특이점목록"], data["계산지표"], 지표명="온라인쇼핑 거래액"
)
print(해석문장_직접지정[0])
# 온라인쇼핑 거래액은 201250억 원로 역대 최대치를 기록하였다.
```

## 완성도 점검

1. 모든 증감률·비중·순위가 `pandas` 계산 함수로 산출되어 오차가 없는가 (비중 합계가 100.0%인지 확인)
2. 특이점 임계값(5%) 기준이 품목별 데이터에 일관되게 적용되었는가
3. 감소 케이스(생활용품 -2.1%)가 임계값 미만이라 특이점 목록에서 제외된 이유를 설명할 수 있는가
4. `역대최대여부`가 과거 이력 데이터만으로 자동 계산되었는가 (사람이 직접 조사해서 입력하지 않았는가)
5. `해석문장`의 지표명이 어색하게 나온다면(예: "동향은"), 그 원인(제목의 마지막 단어를 그대로 쓰는 로직)을 설명할 수 있는가
