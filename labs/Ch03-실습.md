## 실습 목표

- 형태소 분석(Kiwi) + TF-IDF로 원문에서 핵심 키워드를 추출한다.
- TextRank(PageRank)로 원문 그대로의 주요 문장을 추출한다.
- 키워드와 주요 문장을 결합해 규칙 기반으로 문서 주제를 요약한다.
- 아직 생성형 AI를 쓰지 않고도 이런 분석이 가능하다는 것을 직접 확인한다.

## 1단계. 형태소 분석으로 명사만 뽑아보기

> 개념 참고: 강의안 소주제 1 (페이지 7~8, TF-IDF 원리와 한국어 형태소 분석기)

```python
from modules.nlp import extract_nouns

print(extract_nouns("온라인쇼핑 거래액은 전월 대비 1.5% 증가하였다."))
```

**예상 출력**

```
['온라인쇼핑', '거래액', '전월', '대비', '증가']
```

**확인할 점**: "온라인쇼핑"이 "온라인"+"쇼핑"으로 쪼개지지 않고 하나의 명사로 나옵니다. [modules/nlp.py](../modules/nlp.py)가 모듈을 불러오는 시점에 `_kiwi.add_user_word("온라인쇼핑", "NNP", 0.0)`로 사용자 사전에 미리 등록해 두었기 때문입니다 — 기본 사전만 쓰면 실제로 둘로 쪼개지는 문제가 있었다는 것이 코드 주석에 남아 있습니다.

## 2단계. TF-IDF로 핵심 키워드 추출하기

> 개념 참고: 강의안 페이지 9~10 (문서 1건일 때의 TF-IDF 한계와 문장 단위 코퍼스 전략, 불용어 후처리)

```python
from modules.nlp import extract_keywords_tfidf

keyword_scores = extract_keywords_tfidf(data["원문"], top_n=5)
keywords = [w for w, _ in keyword_scores]
print(keyword_scores)
print(keywords)
```

**실제 실행 결과** (myvenv에서 직접 검증 — 점수는 소수점 아래 값이 라이브러리 버전에 따라 조금 달라질 수 있고, 순서와 단어가 같으면 정상입니다. 출력의 `np.float64(...)`는 numpy 2 이상에서 숫자가 그렇게 표시되는 것입니다.)

```
[('온라인쇼핑', np.float64(0.5086...)), ('전월', np.float64(0.5086...)), ('기록', np.float64(0.5)), ('기준', np.float64(0.5)), ('역대', np.float64(0.5))]
['온라인쇼핑', '전월', '기록', '기준', '역대']
```

점수 차이가 거의 없다는 점(0.5087과 0.5)이 이 방식의 특징입니다. 문장 하나하나를 독립된 문서로 취급하기 때문에 단어들의 점수가 비슷하게 나오고, 동점 단어는 사전순으로 정렬됩니다.

**왜 "거래액"·"최대"·"모바일쇼핑"이 빠졌을까?** `extract_keywords_tfidf`는 원문 한 건을 문장 단위로 쪼개 각 문장을 독립된 "문서"처럼 취급합니다(원문이 1건뿐이면 IDF를 계산할 비교 대상이 없기 때문 — 강의안 페이지9 참고). 그 결과 다른 문장과 단어를 거의 공유하지 않는 짧은 문장("이는 역대 1월 기준 최대치를 기록한 것이다")의 단어(기록, 기준)가 오히려 상위권에 오르고, 여러 문장에 걸쳐 나오는 "거래액"은 순위 밖으로 밀립니다. 이는 완벽한 랭킹 알고리즘의 결함이 아니라 **단일 문서에 TF-IDF를 적용할 때 생기는 근본적인 한계**입니다 — 결과를 그대로 받아들이되, 이런 한계가 있다는 것을 이해하고 넘어가는 것이 이번 단계의 핵심입니다.

## 3단계. TextRank로 주요 문장 추출하기

> 개념 참고: 강의안 소주제 2 (페이지 13~14, PageRank 원리와 자기유사도 제거)

```python
from modules.nlp import split_sentences, extract_main_sentences

sentences = split_sentences(data["원문"])
print("전체 문장 수:", len(sentences))
main_sentences = extract_main_sentences(sentences, ratio=0.5)
print(main_sentences)
```

**실제 실행 결과**

```
전체 문장 수: 4
['2026년 1월 온라인쇼핑 거래액은 201,250억 원으로 전월 대비 1.5% 증가하였다.', '전년동월대비로는 8.7% 증가한 수치이다.']
```

**왜 "역대 최대" 문장이 빠졌을까?** `extract_main_sentences`는 문장 간 코사인 유사도로 그래프를 만들고 PageRank를 적용합니다. 1·2번 문장은 서로 어휘("증가", "%")를 많이 공유해 선택되었지만, 3번 문장("역대 최대치를 기록한 것이다")은 다른 문장과 공유 어휘가 적어 선택되지 않았습니다. 이는 원문에 새 문장을 지어내지 않고 **원문 그대로만 고르는 방식**이 갖는 자연스러운 특성입니다.

## 4단계. 키워드로 주요 문장 다시 필터링하기

> 개념 참고: 강의안 소주제 3 (페이지 17~18, 이중 필터링으로 규칙 기반 요약 만들기)

```python
from modules.nlp import filter_sentences_by_keywords

final_sentences = filter_sentences_by_keywords(main_sentences, keywords)
print(final_sentences)
```

**실제 실행 결과**

```
['2026년 1월 온라인쇼핑 거래액은 201,250억 원으로 전월 대비 1.5% 증가하였다.']
```

2단계의 핵심키워드(`온라인쇼핑, 전월, 기록, 기준, 역대`)와 3단계의 주요문장을 다시 대조하면, "기록"·"기준"·"역대"를 담은 3번 문장이 애초에 주요문장 목록에 없었기 때문에 최종적으로는 1번 문장 하나만 남습니다. **TF-IDF(키워드)와 TextRank(주요문장)는 서로 독립적인 알고리즘이라 항상 일치하지는 않는다**는 것을 실제 데이터로 확인한 것입니다. 이 결과가 보도자료의 사실관계를 훼손하지는 않습니다 — "역대 최대치 경신"이라는 사실은 5차시의 `add_calculated_indicators`(규칙 기반 계산)가 `통계해석결과.특이점목록`에 별도로 확실하게 담아내므로, 최종 보도자료 작성은 이 NLP 결과가 아니라 5차시의 검증된 계산 결과를 근거로 진행됩니다.

## 5단계. 세 기능을 통합 함수로 한 번에 실행하기

**예상 출력** (1~4단계와 동일한 결과가 한 번에 나와야 합니다)

```json

  "주요문장": ["2026년 1월 온라인쇼핑 거래액은 201,250억 원으로 전월 대비 1.5% 증가하였다."]
```

## 완성도 점검

1. 핵심 키워드가 실제 원문에 등장하는 단어로만 구성되었는가
2. 주요 문장이 원문 문장과 토씨 하나 틀리지 않고 일치하는가 (TextRank는 새 문장을 만들지 않고 원문에서 그대로 고르므로, 이 단계에서는 환각이 발생할 수 없습니다)
3. `data/processed/press_data.json`에 `NLP분석결과` 필드가 정상적으로 추가되었는가
4. 왜 "역대 최대" 문장이 최종 결과에서 빠졌는지 스스로 설명할 수 있는가 (TF-IDF와 TextRank가 독립 알고리즘이기 때문)
