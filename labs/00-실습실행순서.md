### 4-1. pandas로 증감률·비중·순위 계산 [Ch05-1단계]

```python
import pandas as pd

category_df = pd.DataFrame({
    "품목": ["의류", "가전", "식품", "생활용품", "기타"],
    "당월거래액": [65000, 52000, 48000, 26250, 10000],
    "전월거래액": [64200, 48500, 45100, 26800, 9676],
})
category_df["전월대비증감률"] = (
    (category_df["당월거래액"] - category_df["전월거래액"]) / category_df["전월거래액"] * 100
).round(1)
category_df["비중"] = (category_df["당월거래액"] / category_df["당월거래액"].sum() * 100).round(1)
category_df["순위"] = category_df["당월거래액"].rank(ascending=False).astype(int)
print(category_df)
```

체크: 비중 합계 100.0% (32.3/25.8/23.9/13.0/5.0).
