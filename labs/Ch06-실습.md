## 0단계. 표준 데이터 불러오고 품목별·월별 데이터 추가하기

5차시 표준 데이터에는 아직 그래프로 그릴 품목별 표와 월별 이력이 없습니다. 5차시에서 계산한 값을 그대로 옮겨 담습니다.

```python
import sys, json
sys.path.insert(0, ".")

with open("data/processed/press_data.json", encoding="utf-8") as f:
    data = json.load(f)

data["품목별지표"] = [
    {"품목": "의류", "당월거래액": 65000, "전월대비증감률": 1.2, "비중": 32.3, "순위": 1},
    {"품목": "가전", "당월거래액": 52000, "전월대비증감률": 7.2, "비중": 25.8, "순위": 2},
    {"품목": "식품", "당월거래액": 48000, "전월대비증감률": 6.4, "비중": 23.9, "순위": 3},
    {"품목": "생활용품", "당월거래액": 26250, "전월대비증감률": -2.1, "비중": 13.0, "순위": 4},
    {"품목": "기타", "당월거래액": 10000, "전월대비증감률": 3.3, "비중": 5.0, "순위": 5},
]
data["월별이력"] = [
    {"연월": "2025-10", "값": 189000},
    {"연월": "2025-11", "값": 195000},
    {"연월": "2025-12", "값": 198276},
    {"연월": "2026-01", "값": 201250},
]
```

> 비중 수치(32.3/25.8/23.9/13.0/5.0)는 5차시 1단계에서 `pandas`로 실제 계산한 값입니다. 강의안 예시의 32.4/25.9 등은 반올림이 정확히 검증되지 않은 값이므로, 이 실습에서는 실제 계산 결과를 그대로 씁니다.

## 1단계. 개별 그래프 함수로 막대·원형 그래프 그려보기

> 개념 참고: 강의안 소주제 1 (페이지 7~8, 그래프 유형별 용도)

```python
import os
import matplotlib
matplotlib.use("Agg")  # 화면 없이 파일로만 저장 (Windows Tcl/Tk 문제 회피)
import matplotlib.pyplot as plt
import pandas as pd

os.makedirs("images", exist_ok=True)
plt.rc("font", family="Malgun Gothic")

품목_df = pd.DataFrame(data["품목별지표"])
plt.bar(품목_df["품목"], 품목_df["당월거래액"], color="#4C72B0")
plt.title("2026년 1월 품목별 온라인쇼핑 거래액")
plt.ylabel("거래액(억 원)")
plt.savefig("images/ch06_연습_막대.png", dpi=150, bbox_inches="tight")
plt.close()
print("저장 완료: images/ch06_연습_막대.png")
```

실행 후 `images/ch06_연습_막대.png` 파일이 실제로 생성되었는지 열어서 확인합니다.

## 2단계. 그래프 유형별 설명문 자동 생성하기

> 개념 참고: 강의안 소주제 2 (페이지 11~13, 막대·원형·꺾은선 설명문 템플릿)

```python
from modules.charts import generate_chart_description

bar_desc = generate_chart_description("bar", 품목_df)
pie_desc = generate_chart_description("pie", 품목_df)
print("막대그래프 설명:", bar_desc)
print("원형그래프 설명:", pie_desc)
```

**실제 실행 결과**

```
막대그래프 설명: 의류이 65,000억 원으로 가장 높았으며, 가전이 52,000억 원으로 그 뒤를 이었다. 반면 기타은 10,000억 원으로 가장 낮은 수준을 보였다.
원형그래프 설명: 품목별 비중을 살펴보면 의류이 전체의 32.3%로 가장 큰 비중을 차지하였으며, 가전(25.8%), 식품(23.9%)이 그 뒤를 이었다.
```

조사가 어색한 부분("의류**이**", "기타**은**")이 보이나요? 규칙 기반 템플릿은 문법적으로 올바른 조사를 자동으로 고르지 않습니다. 이 어색함은 6단계에서 LLM으로 다듬습니다.

## 3단계. 꺾은선그래프(시계열) 설명문까지 함께 만들기

> 개념 참고: 강의안 페이지 11 (추세 설명문 템플릿, "지표명이 반드시 있어야 하는 이유")

```python
이력_df = pd.DataFrame(data["월별이력"]).rename(columns={"값": "거래액"}).sort_values("연월")
line_desc = generate_chart_description("line", 이력_df, label="온라인쇼핑 거래액")
print(line_desc)
```

**실제 실행 결과**

```
온라인쇼핑 거래액은 2025-10부터 2026-01까지 증가세를 보이고 있으며, 2026-01에 201,250억 원을 기록하였다.
```

**중요**: `label` 인자를 반드시 넘겨야 합니다. `label`을 생략하면 기본값(`PRIMARY_INDICATOR`, "총거래액")이 쓰이는데, 만약 이 설명문에 주어가 전혀 없으면 8차시에서 AI가 본문으로 확장할 때 "이게 정확히 무엇에 대한 추세지?"라고 혼자 추측하다가 엉뚱한 주제를 지어내는 환각이 실제로 관찰된 적이 있습니다. 그래프 설명문에는 항상 "무엇에 대한 설명인지"가 명확히 드러나야 합니다.

## 4단계. `build_visual_descriptions`로 그래프+설명문 통합 생성하기

> 개념 참고: 강의안 페이지 21 (통합 함수)

지금까지 1~3단계에서 손으로 나눠 실행한 것을, 실제 파이프라인은 `build_visual_descriptions()` 하나로 처리합니다. 이 함수는 `품목별지표`가 있으면 막대+원형 그래프를, `월별이력`이 있으면 꺾은선 그래프를 조건부로 생성합니다.

```python
from modules.charts import build_visual_descriptions

결과 = build_visual_descriptions(data)
for 항목 in 결과:
    print(f"[{항목['그래프유형']}] {항목['소주제']} → {항목['이미지경로']}")
    print("  ", 항목["설명문"])
```

**실제 실행 결과** (직접 실행해 확인함 — `images/` 폴더에 실제 파일 2개 생성됨)

```
[막대그래프] 품목별 동향 → images/2026년 1월 온라인쇼핑 동향_품목별.png
   의류이 65,000억 원으로 가장 높았으며, 가전이 52,000억 원으로 그 뒤를 이었다. 반면 기타은 10,000억 원으로 가장 낮은 수준을 보였다.
[원형그래프] 품목별 비중 → images/2026년 1월 온라인쇼핑 동향_품목별.png
   품목별 비중을 살펴보면 의류이 전체의 32.3%로 가장 큰 비중을 차지하였으며, 가전(25.8%), 식품(23.9%)이 그 뒤를 이었다.
[꺾은선그래프] 시계열 동향 → images/2026년 1월 온라인쇼핑 동향_추이.png
   총거래액은 2025-10부터 2026-01까지 증가세를 보이고 있으며, 2026-01에 201,250억 원을 기록하였다.
```

**확인할 점**: 막대그래프와 원형그래프 두 항목이 **같은 이미지 경로**(`..._품목별.png`)를 가리킵니다. 실제로 한 장의 이미지 안에 막대(왼쪽)와 원형(오른쪽) 그래프가 나란히 그려지기 때문입니다(`plt.subplots(1, 2, ...)`). 본문에는 "품목별 동향"과 "품목별 비중" 두 단락이 생기지만 실제 이미지는 한 장을 공유한다는 점을 기억해 두세요 — 최종 문서에 그래프를 삽입할 때(10차시) 헷갈리지 않기 위해서입니다.

꺾은선그래프 설명문의 주어가 `"총거래액"`으로 나온 것도 확인하세요 — `build_visual_descriptions`가 `generate_chart_description("line", ...)`을 호출할 때 `label` 인자로 `modules/config.py`의 `PRIMARY_INDICATOR`("총거래액")를 명시적으로 넘기기 때문입니다.

## 6단계. (선택, API 비용 발생) LLM으로 설명문 다듬기

> 개념 참고: 강의안 페이지 16

```python
from modules.write import client, MODEL_NAME

polish_prompt = f"""다음 문장들의 조사와 어순을 자연스럽게 다듬어 보도자료 문체로 바꿔주세요.
숫자나 사실은 절대 변경하지 마세요.

1. {결과[0]['설명문']}
2. {결과[1]['설명문']}"""

message = client.messages.create(model=MODEL_NAME, max_tokens=400,
                                  messages=[{"role": "user", "content": polish_prompt}])
print(message.content[0].text)
```

**예시 실행 결과** (실제로 한 번 실행해 확인한 값 — 표현은 매번 달라질 수 있습니다)

```
1. 의류가 65,000억 원으로 가장 높았으며, 가전이 52,000억 원으로 그 뒤를 이었다. 반면 기타 품목은 10,000억 원으로 가장 낮은 수준을 보였다.
2. 품목별 비중을 살펴보면 의류가 전체의 32.3%로 가장 큰 비중을 차지하였으며, 가전(25.8%), 식품(23.9%)이 그 뒤를 이었다.
```

어색했던 조사("의류이" → "의류가")가 자연스럽게 수정되고, 숫자는 그대로 유지되었는지 확인합니다.

## 완성도 점검

1. `images/` 폴더에 그래프 이미지 파일이 실제로 저장되었는가
2. 꺾은선그래프 설명문에 반드시 있어야 할 주어(지표명)가 빠지지 않았는가
3. 막대·원형 두 항목이 같은 이미지 경로를 공유한다는 것을 이해했는가
4. `시각자료설명`의 각 항목에 `소주제` 필드가 있는가 (8차시가 이 필드로 본문 단락의 주제를 결정합니다)
